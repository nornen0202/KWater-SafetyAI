# 첫 인용 제한적 교정의 새 현장 눈가림 검증

## 표본과 판정 방법

이 실험은 v3가 생성한 예방문을 고정하고 첫 인용만 바꾸는 정책을 평가한다. 정책은 이전 9건 검수 시점의 `ee1c3bd`로 고정했다. 정책이 실제로 작동하는 사진과 동일 코드의 무변경 대조를 별도로 확보하고, 미리 동결한 정성 패널의 판독 결과도 기록한다. [개발 단계의 9건 검수](fold4-citation-alignment-20261128.md)

기존 24장 중 검수한 8그룹과 겹친 4장을 교체했다. 원래 107장 평가 범위에서 이전 패널과 검수 그룹을 모두 제외하면 교체 후보는 10장이었다. 남은 20장의 슬롯을 유지하고, 원래 슬롯의 정상·중대·기타 구성을 우선 보존한 뒤 출처 수와 구성을 맞추는 사전 순서로 새 그룹 네 곳을 골랐다. 동결 결과는 **24장·24그룹, 정상 3·중대 10·기타 11, 출처 5종**이다. 기존 정상 5·중대 9·기타 10, 출처 7종과 구성 차이가 있다. 원래 세 모델의 봉인 배정은 보관했고 이번 두 인용 비교에는 별도의 익명 배정을 발급했다. [재동결 원장](../results/fold4-citation-review-panel-v2.json)

동결 패널 24장의 현행 첫 에폭에서 실제 변경은 0건이었다. Fold 4 전체 175장에서 검수 그룹을 제외하면 31장이 남으며 첫 에폭과 두 번째 에폭 모두 변경 가능 행은 0건이다. 서울 6·7·8차가 처리한 동일 200장에서는 검수 그룹 밖 사진이 191장이었고 세 출력 모두 변경 가능 행이 0건이었다. 저장된 최종 출력만 있는 경우 교정안에 가장 유리한 대체 조문을 허용하고 거부 조건에만 작용하는 장면 설명을 생략해 상한을 계산했다. 동일 사진을 여러 모델이 처리한 횟수를 새 현장 수로 합산하지 않았다. [검사 코드](../kwater_lab/citation_review_panel.py)

새 현장 모집에는 AI-Hub 71407의 공급자 훈련 분할을 사용했다. 기존 외부 진단·큐레이션에 쓰인 7개 현장을 제외하고 전도·협착·화재 영상의 중앙 프레임을 예측 열람 전에 동결했다. **12개 공급자 현장·37개 영상·서로 다른 사진 37장**이다. 공급자 분류는 모집에만 사용한다. 공식 안전 코드와 법령 정답은 따로 없고, 공급자 현장 번호와 대회 현장 그룹 간에는 공통 식별자가 없다. 동결 정책이 실제로 바꾼 출력에서 현장당 1건을 고르고, 같은 생성 위험 코드가 있으면서 인용을 유지한 다른 현장 사진과 짝짓는다. 대조 사진·현장을 다시 쓰지 않는다. ## 두 판독자에게 제시한 내용

두 판독자는 서로 다른 오프라인 시각언어모델 **LiquidAI LFM2-VL-450M**과 **Qwen3.5-0.8B**다. 각각 별도 프로세스로 CPU에서 생성하며 사진, 동일한 v3 관찰·예방문, A/B 조문 발췌만 본다. 한 판독자의 A/B 배치는 다른 판독자와 반대다. 정책 이름·공식 정답·공급자 라벨·다른 모델의 답은 숨긴다. 조문이 길면 두 후보에 같은 규칙으로 제목과 관련 행을 제시하고 발췌 표식을 붙인다. 사진 24장 중 v3가 위험을 출력한 15장은 위험행 18개, 위험 없음으로 출력한 9장은 각각 한 문항이다. 주석상 정상 수와 모델의 위험 없음 출력 수는 별도 분모다. [오프라인 판독기](../kwater_lab/citation_blind_judges.py) · [LFM2 모델](https://huggingface.co/LiquidAI/LFM2-VL-450M-GGUF) · [Qwen 체크포인트](https://huggingface.co/unsloth/Qwen3.5-0.8B-GGUF)

두 조문 각각에 대해 ① 실제 예방행동 지지와 ② 사진·위험 대상에 대한 적용 적합성을 직접·부분·무관·판단불가로 매긴다. 예방조치가 양쪽에 동일하므로 ③ 안전순서는 사진과 공통 예방문에 대해 안전·위험·불명확·해당없음으로 한 번 판정한다. 원본 사진은 동일한 축소·JPEG 설정으로 두 판독기에 제공한다. 생성 실패·판정불가를 승패에서 제외할 때는 그 분모도 함께 기록한다. 두 판독기의 전체 원응답 지문을 고정한 뒤 익명키를 열어 결과를 합산한다.

이미 검수한 화기·기계 사례 2개에는 대상과 맞는 조문과 명백히 다른 지붕 조문을 제시했다. 각 사진에 두 번씩 평가를 받아 한국어 조문 구별 능력을 진단한다. 이 4회는 새 현장 효과에서 제외한다. 동일 조문에 점수 차이를 주는 빈도, 진단 문항에 대한 선호, 두 판독자의 방향 일치까지 함께 본다. **실제 변경 사례가 없거나 판독자가 명백한 대조를 구별하지 못하면 해당 실험에서 제출 교체를 지지하는 근거가 없다.** 두 모델의 평정은 현장 전문가 검토나 공식 정성 30점과 별개다.

## 판독자 자체 검증

첫 판독은 각 모델 31회로, 패널 27문항과 진단 4회 전부에서 실제 모델 응답을 회수한 뒤 배정 키를 열었다. LFM은 패널 24/27개, Qwen은 17/27개가 완결된 평정이었다. 두 모델에서 모두 유효한 15개에서도 조치 지지와 조문 적합성의 양쪽 우열을 판단할 수 있는 건은 0개였다. LFM이 공통 안전순서를 위험으로 본 1개 외에는 양쪽 모두 유효 응답에서 해당없음으로 판정했다. 진단에서도 직접 관련된 조문을 선택한 건은 두 모델 모두 0건이었다. 긴 서술이 토큰 상한에서 잘린 응답은 무효로 집계했다. [첫 판독 전체 집계](../results/citation-review-panel-readings.json)

긴 척도의 실패를 확인한 뒤 짧은 비교 형식을 별도 실험으로 고정했다. 같은 장면과 조문을 보고 지지·적합성 각각에 A·B·동률·판단불가 중 하나를 고르고, 공통 안전순서를 한 번 판정한다. 모델과 기존 판독 결과를 보존했다. 앞선 두 진단 사진과 다른 훈련측 5개 그룹의 S4 쉬운 법령 대조에 먼저 적용했다. 두 모델 모두 5/5 유효했고, 조치에 맞는 조문을 LFM은 **4/5**, Qwen은 **1/5** 골랐다. 규율 대상 적합성은 둘 다 **4/5**였다. 안전순서는 두 모델이 3/5건에서 같은 답을 냈다. 안전순서의 별도 전문가 정답은 없었다. 이 결과로는 특히 Qwen의 예방행동 지지 판정을 제출 교체 근거로 쓰기 어렵다. [별도 개발 대조 5건의 실제 응답 집계](../results/citation-review-validation-relative-readings.json)

새 현장에서 서로 다른 두 곳 이상의 변경·대조쌍을 확보하지 못할 경우에 대비해, 공급자 검증 분할에서 앞선 37장과 영상·픽셀이 겹치지 않는 **추가 37장·7현장**도 출력 열람 전에 동결했다. 이 7개 현장은 앞선 12개 현장에 포함된다. 예비 표본을 사용하면 전체 현장 수를 12로 유지하고 실제 변경·대조쌍은 현장 중복 없이 다시 선정한다. [예비 표본 원장](../results/citation-reserve-site-inputs.json)

## 같은 조문에서 나타난 판독 오차

짧은 비교 양식으로 재동결 패널 27문항을 다시 판독했다. 두 모델의 응답이 모두 유효한 23문항 중 공통 안전순서 판정은 10건에서 일치했다. 실제 조문이 같은데도 두 모델은 자주 한쪽을 골랐다. 아래 표의 선호는 A나 B를 택한 횟수다. [단축 판독 전체 집계](../results/citation-review-panel-relative-readings.json)

| 동일 조문 비교 | LFM2-VL-450M | Qwen3.5-0.8B |
|---|---:|---:|
| 전체 유효 응답 | 23/27 | 27/27 |
| 위험행에서 예방조치 지지에 우열을 부여 | 16/16 | 7/18 |
| 위험행에서 조문 적합성에 우열을 부여 | 16/16 | 18/18 |
| 위험행의 공통 안전순서 | 위험 11, 해당없음 5 | 안전 2, 해당없음 16 |
| 위험 없음 출력에서 조문 적합성에 우열을 부여 | 7/7 | 8/9 |

위험 없음 출력에는 어느 쪽에도 제시할 예방문이나 조문이 없었다. LFM은 그중 2건에서도 예방조치 순서를 위험으로 판정했다. 이 양식의 표결 수는 조문 교체의 독립적인 채택 근거로 사용하기 어렵다.

참고로 정책을 설계할 때 본 화기·바닥 정리·기계 방호 3개 현장의 **실제 현행·교정 조문**과, 다른 3개 현장의 같은 코드 무변경 대조도 별도 배정으로 판독했다. 두 모델 모두 변경 3건 중 조문 적합성에서 교정을 1건, 현행을 2건 선호했다. 두 모델은 동일 조문 대조 3건에서도 똑같이 교정 1건·현행 2건을 골랐다. 변경 3건에서 예방조치 지지는 LFM이 교정 1·현행 2, Qwen이 교정 1·동률 1·현행 1이었다. 공통 안전순서는 2/3건 일치했다. 이미 검수한 변경 사례에서 얻은 이 수치는 새 현장 재현 횟수에서 제외했다.
