## V1. 고정 확대와 사람이 정한 확대 위치 비교

CPU에서 144개 이미지 해시, 동일 사진 48세트의 왼쪽 원경 픽셀, 프롬프트 및 Fold 0 v2 118스텝 어댑터 지문을 다시 확인했다. 48장은 38그룹, 공식 정상은 12장이다. 별도 눈가림 시각 관계는 **지지 11·반대 1·불명확 36**이었다. 사진의 관계를 지지하는 11장을 학습 정답 양성 24장과 혼동하면 확대 효과가 과장된다. [검수 원장](../results/vision-roi-review-20261127.json)

서울 실행은 같은 4B·BF16·393,216화소·batch 1·greedy 620토큰으로 고정했다. 같은 원경 옆에 ① 고정 위치 60% 창, ② 사람이 고른 위치 60% 창, ③ 표시한 영역이 모두 들어오도록 넓힌 창을 둔다. 세 번째는 24장의 배율도 달라진다. 비공개 실행 패킷에는 모델에 보여줄 사진·입력과 검증용 지문, 어댑터, 코드가 있다. 공식 정답 키와 검토자의 서술은 팀 로컬에서 채점할 때만 쓴다. 원본 크기의 원경 단독 조건은 확대의 추가 연산까지 비교할 후속 대조로 따로 측정한다.

각 비교에서 **회복 TP, 잃은 TP, 새 FP, 제거 FP, 정상 사진 오경보의 순변화, 파싱 실패**를 전체·위험 유형·관계 판독별로 공개한다. 순이득의 정의는 `(회복 TP − 잃은 TP) − (새 FP − 제거 FP)`다. 유효 출력이 다른 사진을 조용히 분모에서 빼지 않는다. 기존 어댑터의 훈련과 겹칠 수 있는 개발 진단이므로 독립 Fold 4 성능으로 합산하지 않는다. 유리한 수동 확대 효과가 확인된 경우 고정된 예산으로 전문가 패치 기여도와 Qwen 좌표 생성을 비교한다. ## V3와 자원 순서

1. **현재 CPU**에서 S1·V2의 고정 비교를 완료했다. S2 검토와 S4 어려운 음성 대조의 적격성 판독은 GPU와 독립적이다.
2. **클라우드**는 기존 제출 키트·동일 예산 학습 담당 세션이 먼저 사용한다. 비전 세션은 중복 실행 0건을 확인했다. V1 비공개 패킷(219,629,939바이트, SHA-256 `e086736e110d5182b31c9c3911f128688347b4b4b0e8fbedd7b4afe34da69309`)과 실행 요청을 서울 담당자에게 전달했다. 확보한 슬롯에서 3개 캐시를 회수한 뒤 로컬 정답으로 비교한다. 서울 Spot L4에서 8B 본학습이 시작됐고, 이 원장의 Qwen ROI 완료 건수는 0/144다. 슬롯 배정 시점은 미확정이다.
3. **V3 개방어휘 탐지**는 수동 확대가 유리하고, 원경·고정창과 비교해 확인한 순이득의 절반도 무가중치 자동 확대가 회수하지 못할 때 개시한다. 이때만 구체 물체·작업자 간 관계를 위한 Florence/Grounding DINO 크롭을 시험한다. 임계값은 개발에서 고정하고 실제 후보당 지연과 정상 오경보를 함께 본다. 마스크 생성과 캡션 추가는 각각 별도 대조다. 현재는 탐지기 도입에 쓸 근거가 없다.
4. **메인 GPU와 제출**은 기존 담당자가 유지한다. 정성 판독과 170장 깊이 F1을 Public 점수로 환산하지 않는다. 이후 동일 모델·정책으로 새 그룹 검증과 실 ZIP 200장 시간, 독립 재현성까지 합류시킨다.

## 재현과 검토 범위

저장소 루트에서 `python -m kwater_lab.qualitative_gate_pilot`, `python -m kwater_lab.vision_gate_depth_probe`를 실행한다. ROI 사전검사는 `python -m kwater_lab.vision_gate_roi_run`, 팀 전용 서울 GPU 실생성은 같은 명령에 `--base <로컬 4B 디렉터리>`를 추가한다. 결과 세 캐시를 회수한 후 `python -m kwater_lab.vision_gate_roi_score --caches <캐시 폴더>`로 채점한다. 제출 재현성은 `python -m kwater_lab.compare_kit_repeats <1회 영수증> <2회 영수증>`으로 확인한다.

검토 근거에는 첨부 답변 두 건, 이슈 원문, 두 로드맵의 직접 연결 문서와 JSON, 공식 준비·출력 코드, 정성·검색·전문가 코드가 포함된다. 이슈의 다섯 이식안은 각각 S1의 검색, S2·S3의 학습, S3의 유보, S4의 독립 심사, S2의 안전순서에 연결된다. 제미나이가 언급한 `output.txt`는 전체 경로·지문이 없어 같은 파일임을 특정할 수 없었다. 첨부 로그상 이슈 #2 본문 추출 직후의 임시 출력으로, 공개 이슈 본문을 직접 확인하고 해당 수치에는 동결 JSON·실제 재생 결과를 사용했다. 비전 분기는 과거 탐지·마스크 실행, 공개 모델 원장, 170장 깊이·교환 대조, Ubuntu 브랜치의 공간 풀링, 48장 입력 감사, 서울 실행 및 7차 판단 근거와 대조했다.
