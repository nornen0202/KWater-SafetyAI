# 전체 사진 6장에 대한 Qwen3-VL 프롬프트 비교

2026년 11월 26일, 같은 전체 사진 6장을 다섯 조건으로 판독해 모델 응답 30건을 저장했다. 28건은 주최측 출력 검사기를 통과했다. 2건은 최대 출력 길이인 640토큰에서 끝나 제출 행을 만들 수 없었다. 입력 6장을 모두 남긴 각 조건의 manifest를 기준으로 누락까지 계산했다. [생성 집계](../results/prompt_pilot.json) · [공식 형식 검사](../results/prompt_format_replay.json)

## 코드 판정

사진별 비교에서 분모를 맞추기 위해 다섯 조건 모두 완성된 4장을 사용했다. 이 중 위험 사진은 3장이고 무위험은 1장이다. Macro-F1은 정답이나 예측에 한 번 이상 등장한 위험 유형의 F1 평균이다.

| 판독 조건 | 공식 유효 행 / 입력 | Macro-F1 · 공통 4장 | 위험 집합 정확 일치 / 4장 | 무위험 사진 오경보 / 1장 | 전체 입력 토큰 범위 |
|---|---:|---:|---:|---:|---:|
| 8종, 위험 먼저 | 6/6 | 0.267 | 3 | 0 | 396–4,261 |
| 11종, 위험 먼저 | 6/6 | 0.250 | 3 | 0 | 438–4,303 |
| 11종, 장면 관찰 먼저 | 5/6 | 0.200 | 2 | 1 | 439–4,304 |
| 11종, 같은 사진의 인코더 후보 확인 | 5/6 | 0.333 | 1 | 1 | 485–4,343 |
| 11종, 다른 사진의 후보 확인 | 6/6 | 0.333 | 1 | 1 | 481–4,346 |

두 후보 확인 조건은 공통 4장에서 같은 Macro-F1을 냈다. 두 조건만 비교할 수 있는 5장 중 1장에서 위험 집합이 바뀌었고, 정답 집합과 새로 일치하거나 일치를 잃은 사례는 없었다. 장면 관찰을 먼저 한 조건과 같은 사진의 후보를 확인한 조건을 짝지으면, 두 조건 모두 유효한 4장 중 2장에서 집합이 바뀌고 1장에서 완전 일치를 잃었다. 공통 4장에 포함된 복합위험 1장은 어느 조건도 모든 위험을 맞히지 못했다.

8종 위험 우선과 11종 위험 우선은 각각 6장 모두 위험 항목을 첫 필드에 출력했다. 장면 우선과 두 후보 확인 조건의 완성된 응답 16건은 모두 관찰을 첫 필드에 출력했다. 두 길이 초과는 장면 우선과 같은 사진 후보 확인에서 1건씩 발생했다.

## 입력과 실행 측정

원본 PNG 해상도는 486×334, 640×480, 720×1280, 832×609, 2048×512, 3264×2448이 각각 1장이었다. 외부 자르기나 크기 조정을 거치지 않고 Qwen3-VL-4B-Instruct Q4_K_M과 F16 비전 프로젝터의 전처리에 전달했다. 모든 조건은 문맥 8,192토큰, 출력 한도 640토큰, 시드 42, 온도 0을 사용했다. RTX 3060을 사용하는 Windows 로컬 Vulkan 서버가 준비되기까지 1,363.329초 걸렸다. 실행 중 전용 서버와 클라이언트의 운영체제 작업 집합 최소값을 각각 128MiB, 64MiB로 요청했다. 프로젝터 836,180,256바이트를 순차 선읽기한 시간은 37.3초였다. 이 기록만으로 기동 시간 변화의 원인을 분리할 수 없다. [입력·실행 집계](../results/prompt_vision_budget.json)

API의 전체 입력은 사진과 텍스트를 합해 396~4,346토큰이었다. 서버 로그에는 요청 30건의 전체 프롬프트 평가량이 있었고, API 세부 필드는 캐시 토큰 수만 제공했다. 사진만의 실측 토큰 수는 확인할 수 없다. 서버는 위치 판독에서 이미지 토큰 1,024개를 언급하는 경고를 출력했다. 이번 실행에서는 이미지 최소 토큰 옵션을 지정하지 않았다.

앞선 4,096 문맥 실행에서는 서버가 2,434.777초 후 연결을 받았으나 첫 사진의 전체 입력 4,261토큰을 수용하지 못했다. 이 실패를 기록한 뒤 문맥을 8,192로 늘려 별도의 설계로 30건을 처음부터 실행했다. [이전 설계 실행 기록](../results/prompt_preflight_4096.json) · [재현 명령](../docs/paired-vlm-pilots.md)

## 판정 범위

이 6장은 이미 탐색에 사용한 170장에서 CLIP과 SigLIP 2의 후보가 다른 사진을 우선해, 접두사별로 정답을 보지 않고 골랐다. 동일 사건 여부가 검증되지 않아 독립 사건 성능이나 대회 순위를 추정할 수 없다. 사람이 사진과 조치를 비교할 수 있도록 블라인드 응답 28개, 판정쌍 14개를 로컬에 저장했다. 관측 근거의 정확성과 예방 조치 실행 가능성에 대한 사람 평가는 아직 없다. 공식 검사는 행 형식만 확인하며 법령 참조는 이 비교에서 빈 목록으로 뒀다.
