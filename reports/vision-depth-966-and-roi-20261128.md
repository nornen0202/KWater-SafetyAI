# 인양 깊이 966장 그룹 검증과 서울 ROI 144건

**11월 28일 최종 판정은 두 모듈 모두 이번 제출에서 보류다.** 수동 ROI는 목표 위험을 더 찾았지만 정상 사진에서도 두 장 더 경보를 냈다. 깊이는 966장 인양 F1과 서울 L4의 추가시간 기준을 모두 통과하지 못했다.

## V1 서울 L4에서 같은 48장을 세 번 판독한 결과

8B 학습과 예약된 두 에폭 평가가 끝난 뒤 서울의 기존 L4에서 08:04:08~08:32:19 KST, 28분 11초 동안 실행했다. 같은 Qwen3-VL-4B, Fold 0 v2 118스텝 어댑터, 같은 원경·프롬프트로 오른쪽 확대 창만 바꿨다. 38개 그룹의 사진 48장 중 지정한 위험이 있는 사진은 24장, 공식 정상은 12장이다. 미끄러짐·추락·인양 각 16장에서 지정한 한 코드의 TP·FP·FN을 합쳐 F1을 계산했다. 정상 오경보는 코드 종류와 상관없이 한 건이라도 출력한 사진 수다. 배율을 맞춘 비교에서는 TP 3건을 회복하고 2건을 잃었으며 FP 1건이 늘어 사전 정의한 순이득은 0건이었다. 전체 영역을 보존하면 TP 3건을 회복하고 1건을 잃었으며 FP 1건이 늘어 순이득은 +1건이었다. 이 조건은 24장의 배율도 바뀐다. 두 수동 조건 모두 정상 오경보가 1/12에서 3/12로 늘었다. 전체 보존 조건에서 시각 관계가 불명확한 36장은 목표 정답 2건과 정상 오경보 2건이 함께 늘었다. 관계를 지지한 11장은 목표 TP 1건 회복·1건 손실·FP 1건 추가, 관계를 반박한 1장은 변화가 없었다.

세 조건 모두 원생성 JSON 파싱·스키마를 48/48 통과했고 토큰 상한에 걸린 사진도 없었다. 첫 실행 시간 제한 시 캐시에 남은 48·48·34건을 검증한 뒤 남은 14건만 생성했다. 로컬 채점 시 반환 압축파일, 세 캐시, 입력 이미지, 모델·프롬프트 지문을 대조했다. 목표 F1의 상승에도 동일 배율에서 순이득이 없고 정상 손실이 두 조건에서 재현돼 V1-a/b 자동 크롭과 V3 탐지·분할의 GPU 우선순위는 보류한다. 추후 별도 현장에서 확인할 가치가 있는 질문은 원경 단독 대비 불명확 사례의 미탐 회복이 정상 손실 없이 유지되는가이다. 이 48장은 개발 패널로 175/107장이나 리더보드의 성능 증가를 추정하는 데 쓰지 않는다.

## V2 서울 L4에서 측정한 200장 추가시간

공식 키트 리허설과 같은 200개 이미지 바이트에서 JPEG 디코딩만 22.25초, 디코딩과 DA-v2 깊이 특징 계산은 34.57초였다. **추가 12.31초**, 모델 로드 1.06초를 포함하면 **13.38초**다. 이 모듈만으로 사전 허용치 10초를 2.31초 넘겼다. ONNX Runtime 1.23.2 CUDA에서 두 조건의 순서를 사진마다 교대했다. 이 시간은 깊이 모듈 증분이며 전체 제출 ZIP의 실행시간은 별도 측정 대상이다. 두 실험은 기존 예산의 같은 서울 Spot L4를 재사용했고, 결과 회수 직후 GPU를 담당 세션에 반환했다. 최종 청구액은 결제 원장에서 확정된다. ## 비교 조건

2026년 11월 28일. 170장 탐색에서 본 인양 신호가 더 많은 현장에서도 유지되는지 시험한다. 공개 개발 966장의 기존 5개 외측 폴드와 192개 현장 추정 그룹을 사용한다. 사진별 깊이는 같은 고정 DA-v2 Small ONNX에서 한 번 계산한다. 170장 탐색 표본도 개발셋에 포함되므로 노출된 개발 결과로 해석한다. [선행 실험](qualitative-vision-followup-20261128.md)

1. 같은 170장 실험의 RGB 커널 SVM과 깊이·밝기·에지·다른 훈련 그룹 깊이 20회 대조를 966장에 적용한다. 분류 비용·커널 가중치·판정 경계는 유지한다. 외측 예측을 한 번씩만 합산한다.
2. 11코드 전문가도 동일 사진·그룹·55에폭·3시드로 RGB, RGB+실제 깊이, RGB+다른 그룹 깊이를 비교한다. 최신 깊이 모델이나 임계값을 외측 결과로 선택하지 않는다. 단일 깊이 지도에서 4×4 셀의 상대 깊이 중앙값과 경계 강도, 상하 차분을 읽어 7개 RGB 뷰에 대응시킨다. 최고 반응 패치 뷰의 위치 좌표는 캐시에 없어 이 뷰에는 원경 깊이를 쓴다. 같은 외측 폴드 안에서는 기존 RGB 전문가의 엄격 내측 OOF 보정 정책을 세 조건에 똑같이 적용한다. 원래 전문가의 보관 OOF도 재학습 기준과 함께 제시한다.
3. 분모는 사진 966장, 정상 위험코드 없는 사진, 실제 인양 양성 사진으로 구분한다. 인양 F1·TP·FP·FN, 정상 사진의 인양 오경보와 모든 코드 오경보, 전체 활성 Macro-F1, 현장 단위 쌍체 부트스트랩 95% 구간을 기록한다.
4. 서울 리허설에 이미 사용한 200장 바이트와 순서로 원경 디코딩과 디코딩+깊이 실제 시간을 비교한다. 두 조건의 순서를 사진마다 교대한다. 깊이 모델 로딩 시간과 200장 증분을 구분한다. 채택 조건은 11코드 전문가에서 인양 F1 ≥.28 및 RGB 대비 ≥.08 상승, 전체 Macro-F1·정상 오경보 비악화, 서울 L4의 200장 추가시간 ≤10초다.
5. 서울 V1은 8B 학습·기예약된 에폭 평가가 끝난 뒤 같은 VM에서만 실행한다. 동일 48장에 고정 타일·같은 배율의 수동 ROI·표시 영역 전체를 보존하는 ROI를 사용한다. 3개 실생성 캐시를 회수해 로컬에서 공식 코드 및 정상 오경보, 관계 판독별 순변화를 비교한다. [ROI 채점 코드](../kwater_lab/vision_gate_roi_score.py)

기존 육안 감사에서 연결된 현장 쌍을 합치면 186그룹이다. 커널 분류기는 각 외측 폴드에서 검증 현장과 연결된 훈련 사진을 제외하고 966장 전부에 대해 다시 예측한다. 11코드 전문가는 정규 966장 평가와 함께, 검증측과 훈련측을 가로지르는 모든 확인된 연결 현장을 평가 분모에서 제외한 562장도 보고한다.

로컬 i5-12400F CPU에서 동결 200장 디코딩은 21.13초, 디코딩과 깊이 추출은 226.90초였다. 추가시간 **205.78초**, 모델 로드까지 합하면 **217.52초**다. 966장 특징 추출도 병행 중이었던 개발 PC 실측이다. 서울에서는 같은 200장 바이트의 지문을 확인했다. [CPU 시간 원장](../results/vision-depth-966-cpu-time-20261128.json)

## 11코드 전문가의 채택 판정

**이번 제출에 깊이를 추가하지 않는다.** 같은 CPU에서 새로 학습한 RGB 전문가와 비교하면 실제 깊이는 인양 정답을 2건 회복한 순효과와 인양 FP 8건 감소를 보였다. 인양 F1 개선은 **+.0289**, 절대 F1은 **.2235**로 사전에 정한 +.08 및 .28에 모두 미달했다. 그룹 부트스트랩 95% 구간은 −.0055~+.0769다. 폴드별 F1 차이는 −.0026, .0000, +.1441, −.0411, +.0300이었다. 원장에 남은 과거 RGB 예측과 CPU 재학습 예측은 달랐다. 새로 학습한 세 조건은 같은 CPU·시드·라벨·보정 정책을 공유한다. 육안 연결 현장을 제외한 **562장(정상 149장)**에서도 RGB→실제 깊이로 인양 F1이 .2075→.2353이었고, 전체 Macro-F1은 .5421→.5417, 전체 위험 오경보는 51→51장이었다. 따라서 원래 목표인 인양 개선과 다른 위험 정확도 보존을 함께 뒷받침하는 결과는 얻지 못했다.
