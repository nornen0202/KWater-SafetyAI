# Fold 2 새 4B 첫 에폭 결과

2026년 11월 28일 로컬 RTX 3060에서 Fold 2를 제외한 개발 사진 769장·154그룹으로 Qwen3-VL-4B-Instruct LoRA를 새로 학습했다. 고정 Fold 2 정본 197장과 민감도 55장 모두 정상 오경보 18% 기준을 초과했다. Fold 2용 8B는 학습하거나 평가하지 않았으며, 두 모델의 Fold 2 비교 결과는 없다. [평가 원장](../results/fold2-v3-4b-epoch1-20261128.json)

열·기상 코드 `thermal_weather` 정답은 두 표본에 공통으로 포함된 한 장에 있다. 모델이 이 코드를 한 번도 출력하지 않아 1건 미탐, F1 0이었다. 활성 Macro-F1에는 이 코드를 포함한다. 공통 8종 Macro-F1은 별도 코드 집합을 고정한 모델 간 참고 지표다. 심각도 4 완전 미탐은 해당 사진의 심각도 4 정답 코드를 하나도 맞히지 못한 경우다.

55장은 과거 노출 원장과 확인된 교차 현장에서 고정한 142장·4그룹을 정본에서 제외한 표본이다. 기존 ROI 시각 검토 사진 16장이 남아 있고 정상은 12장뿐이다. 따라서 두 분모를 함께 보고하고, 다른 현장의 독립 재현은 별도로 확인해야 한다. [노출 원장과 표본 정의](../results/sub78-fold2-prospective-readiness-20261128.json)

### 19장 노출 점검의 정의

19장은 55장에서 기존 ROI 관찰 사진 또는 큐레이션 파일럿 사진과 **같은 매니페스트 그룹**을 추가로 뺄 때 남는 범위다. 선택 규칙과 19장·19그룹이라는 결과는 추론 전에 기록됐고, 당시 19장 개별 명단의 지문은 저장하지 않았다. 기존 ROI·큐레이션 원본과 55장 마스크의 지문을 검증하고 기존 규칙을 그대로 재생해 197장·55장·19장의 원래 분모를 모두 재현했다. 재구성한 19장 명단 지문은 로컬에 보존했다.

같은 197행 예측에서 이 19장의 활성 9종 Macro-F1은 **0.403704**, 공통 8종은 **0.454167**이었다. 정상 오경보는 **0/2**, 심각도 4 완전 미탐은 **2/9**였다. 정상 2장에서는 한 건만 오경보여도 50%이므로 오경보에 관한 견고한 결론을 내리기 어렵다. 이 보조 집계는 정본·55장 결과나 승격 판단을 변경하지 않는다. [19장 탐색 재생 원장](../results/fold2-v3-4b-epoch1-exposure19-replay-20261128.json)

## 학습, BF16 복구, 예측 지문

- 6차와 동일한 v3 혼합 커리큘럼 생성기, 프롬프트, 초기 4B 베이스 리비전 `ebb281ec70b05090aa6165b016eac8ec08e71b17`, seed 42, 393,216픽셀 상한, 학습률 0.00014와 16개 누적을 사용했다. 6차의 기존 LoRA는 불러오지 않았다. Fold 2 훈련측의 엄격한 내측 OOF 769장과 외측 사진·그룹 교집합은 0이다. 이번 커리큘럼은 1,066예제이며 마진 보정은 실행하지 않았다.
- 두 에폭 134스텝 스케줄을 유지하고 첫 에폭 경계 67스텝에서 저장했다. 첫 에폭 가중 토큰 손실 0.9627, 에폭 6,791.5초, 최대 CUDA 할당 6.098GiB였다. 첫 양의 학습률이 적용된 2스텝에서 저장한 LoRA B 텐서 260개에 비영값이 들어 있음을 확인했다.
- 첫 에폭 체크포인트로 BF16 단독 판독을 실행했다. 프롬프트·이미지 상한·생성 상한 620토큰을 유지했다. 44장 뒤 배치 4에서 CUDA 메모리 부족이 발생했고, 로컬 복구 경로에서 앞 44행을 그대로 재사용했다. 실제 배치는 4장짜리 11개, 2장짜리 76개, 마지막 단일 1개였다. 생성 누적 1,641.7초에는 모델 적재 및 실패한 배치가 포함되지 않는다. 원생성 197/197행에서 JSON과 내부 스키마를 확인했고 생성 상한에 닿은 행은 0개였다. 다음 비교에서 이 배치 경계를 맞추면 같은 실행 조건을 더 잘 보존할 수 있다. ## 재현

이미 생성한 로컬 예측의 채점과 배치 검산은 GPU 없이 실행할 수 있다. 정답·원생성·사진별 명단·체크포인트는 `data/`에 둔다.

```powershell
$env:CUDA_VISIBLE_DEVICES = '-1'
$env:OMP_NUM_THREADS = '1'
python -B -m kwater_lab.fold2_v3_epoch1 score
python -B -m kwater_lab.fold2_epoch1_batch_witness
python -B -m kwater_lab.fold2_exposure19_replay
```

학습과 판독을 재실행할 때는 별도 GPU 셸에서 [훈련 큐](../tools/run_fold2_v3_epoch1.ps1)를 사용한다. 큐는 같은 프로젝트의 GPU 잠금을 잡고 첫 에폭 체크포인트, BF16 판독, CPU 채점을 순차 실행한다. 위 메모리 부족 경로는 해당 원생성 캐시가 있는 경우에만 같은 큐의 `-RetryBf16OOM` 옵션으로 재개한다. 완료 시점 15:58:55 KST에 큐 자식 종료와 GPU 잠금 해제를 확인했다.
