# 항목 39 · 920장 개발 OOF와 Linux 제출물 독립 점검

## 중대성 4 사진의 판정

단일 전역·고정 임계값 기준선을 유지한다. 고정한 빈 슬롯 복구 규칙은 기준선보다 pooled Macro F1이 0.003398 높았지만 중대 위험을 완전히 놓친 사진은 96장에서 104장으로 늘었다. 기존 다중 후보에서 무위험으로 판정한 23장은 유지했다.

| 개발 29그룹 · 외측 5분할 | pooled Macro F1 | 중대 완전 미탐 / 270장 | 미탐 중대 코드 / 294건 | 무위험 오경보 / 308장 |
|---|---:|---:|---:|---:|
| 단일 전역 · 고정 0.20 | 0.265786 | 96 | 114 | 308 |
| 다중 스케일 · 클래스별 문턱 | 0.292600 | 109 | 130 | 285 |
| 다중 후보 + 빈 슬롯 1개 복구 | 0.269183 | 104 | 125 | 285 |

중대 정답을 하나라도 맞히면 해당 사진을 검출로 센다. 270장 중 중대 정답이 1개인 사진은 246장, 2개인 사진은 24장이다. 전체 정답이 여러 개인 사진은 93장이며, 이 중 77장은 낮은 중대성 코드도 포함한다. 중대 정답을 전부 놓치면서 낮은 중대성 정답만 맞힌 사진은 기준선 14장, 다중 후보 16장, 수정안 17장이다. 반대로 중대 정답 일부만 맞힌 사진은 16장, 17장, 17장이다.

| 두 원본 정책의 사진별 대조 | 장수 |
|---|---:|
| 두 정책 모두 중대 정답 검출 | 146 |
| 기준선만 검출 | 28 |
| 다중 후보만 검출 | 15 |

`dev_fold-oof.jsonl`의 SHA-256과 개발 헤드의 적합 ID 순서 해시를 검증한 다음, 그 920개 ID에 맞는 정답 레코드만 가져왔다. 평가 경로는 봉인 사진 파일, 봉인 라벨 객체, 봉인 예측과 1,045장 적합 모델을 열지 않는다. 각 개발 그룹의 외측 검증 분할은 그 그룹의 외측 학습 분할과 겹치지 않는다. 10개 원본 캐시에서 실행 서명과 학습·검증 인덱스로 만든 식별자, 3개 내부 분할의 학습 범위, 캐시의 로짓·정책과 저장 OOF의 행별 일치를 확인했다. 두 원본 정책의 예측은 각각 920/920 일치했다. 기존 캐시는 내부 OOF로 고른 정책과 내부 분할 메타데이터, 해당 외측 검증 로짓을 보관한다. 내부 원시 로짓은 저장하지 않았다. 고정 수정안은 추가로 추정할 항이 없어 해당 외측 학습 그룹의 기존 내부 보정을 그대로 적용했다. 별도 조정자가 만든 124장 대조 명단과 중대 정답·기준선·다중 후보·수정 코드 집합도 전부 일치했다.

## 어느 단계에서 중대 코드가 빠졌나

코드별 확률은 `sigmoid(logit / T)`다. 기준선의 T는 전부 1, 문턱은 0.20이다. 다중 후보는 각 외측 학습 그룹의 내부 OOF로 택한 코드별 T와 문턱을 사용한다. 두 비교 정책의 장면 게이트와 순위 오프셋은 0이다. 문턱 이상인 후보들을 보정 확률 내림차순으로 정렬하고 동률은 고정 코드 순서가 앞선 것을 선택해 최대 3개를 출력한다. 원점수 순위, 보정 순위, 통과 후보 내 순위, 해당 코드 문턱만 해제했을 때의 순위를 모두 보존했다.

| 중대 코드를 전부 놓친 사진의 원인 | 기준선 / 96 | 다중 후보 / 109 | 기준선만 검출한 28장 중 다중 후보의 원인 |
|---|---:|---:|---:|
| 문턱만 해제하면 3위 이내 | 0 | 42 | 18 |
| 문턱을 통과했으나 4위 이하 | 94 | 32 | 7 |
| 문턱 미달이며 해당 코드만 허용해도 4위 이하 | 2 | 34 | 3 |
| 같은 사진의 중대 코드들에 원인이 혼재 | 0 | 1 | 0 |

다중 후보의 가장 흔한 단일 원인은 문턱 단독이다. 마지막 처리 단계로 세면 문턱 미달만 발생한 사진은 76장, 순위 탈락만 발생한 사진은 32장, 두 단계가 혼재한 사진은 1장이다. 109장 중 중대 정답이 하나라도 원점수 상위 3개에 든 사진은 23장이다. 기준선에서 새로 악화된 28장 중 21장에서 중대 정답이 문턱에 미달했고 이 중 3장은 해당 문턱만 풀어도 복구되지 않는다.

294개 중대 정답 **코드**를 분모로 세면, 기준선은 검출 180건, 순위 단독 112건, 문턱과 순위 동시 2건이다. 다중 후보는 검출 164건, 문턱 단독 49건, 순위 단독 41건, 문턱과 순위 동시 40건이다. 다중 후보에서 원점수 3위 이내였으나 최종 탈락한 중대 코드는 문턱 단독 18건과 순위 단독 9건이다. 원점수 4위 이하에서 최종 검출로 바뀐 중대 코드는 14건이다.

## 유일한 수정안과 불확실성

사전에 고정한 규칙은 기존 다중 후보가 1~2개를 출력한 사진에만 문턱 미통과 코드의 보정 확률 1위를 하나 추가한다. 추가 튜닝 예산은 0이다. 281장에 코드 하나씩 더해 정답 12건과 오답 269건이 생겼다. 중대 완전 미탐 5장을 복구한 변화는 모두 fold 3에 집중됐다. 무위험 오경보는 기존 다중 후보와 같은 285장이고 기준선보다 23장 적다.

이번 승격 요건 중 pooled F1 개선과 무위험 오경보 ≤308은 충족했지만 중대 미탐 ≤96을 벗어났다. 이전 요건인 ΔF1 ≥0.02, 중대 미탐의 엄격한 감소, 쌍체 구간 하한 >0도 충족하지 못했다. 이 비교는 이미 관측한 개발 분할에서 수행한 원인 점검이다.
