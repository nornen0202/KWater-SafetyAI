# 깊이·객체 검출·분할을 K-water 현장 위험 판독에 쓰는 실험

2026-11-26 · 항목 #38 · **먼저 매달린 하중과 작업자를 한 자르기 안에서 다시 보여주는 방법을 시험한다.** 깊이는 낙하·인양에서만 기존 대조군보다 일관된 신호가 있었다. 추락은 작업자, 단부, 난간을 같은 장면에서 구별하는 검출·분할 과제로 시작한다. 최종 선택은 개발 사진에서 실제로 되찾은 중대 위험과 새 오경보, 설명의 정확성, 전체 제출 시간으로 정한다.

## 1. 기존 깊이 실험에서 확인한 효과

Depth Anything V2 Small의 단안 상대 깊이를 4×4 격자의 32개 특징으로 요약해 CLIP 분류기에 더한 실험이다. Qwen에 깊이 이미지를 입력한 결과로 해석할 수 없다. 이미 탐색한 170장을 6개 출처 접두사로 나눴고 실제 독립 사건 경계는 미확인이다. 아래는 저장된 결과 JSON과 보고서를 다시 대조한 수치다.

| 탐색 170장 | 관측 7종 Macro F1 | 추락 TP / FP / FN | 낙하·인양 TP / FP / FN | 무위험 사진 경보 / 66 |
|---|---:|---:|---:|---:|
| RGB | 0.1950 | 7 / 18 / 27 | 0 / 13 / 19 | 13 |
| RGB + 같은 사진의 깊이 | 0.2212 | 7 / 16 / 27 | 2 / 6 / 17 | 14 |
| RGB + 다른 사진의 깊이 | 0.2152 | 9 / 16 / 25 | 1 / 8 / 18 | 11 |

- 같은 사진 깊이의 낙하·인양 F1은 0.1481이었다. 사후에 추가한 다른 사진 깊이 20회는 0.0000~0.1290이었다. 반면 추락에서는 교환 대조군이 20회 중 10회 동등 이상이었고, 외부 추락 방호 7쌍 중 비정상을 더 위험하게 평가한 경우는 2쌍뿐이었다. 20회는 탐색적 민감도 분석이다.
- 저장한 6개 분할을 다시 대조하면 전체 F1에서 깊이가 RGB를 이긴 경우는 4/6, 처음 지정한 교환 깊이를 이긴 경우는 3/6이었다. 교환 깊이 대비 분할별 변화는 −0.0563~+0.1029였다. 170장 통합 점수의 상승을 모든 현장에 적용하기 어렵다.
- 깊이 특징만 RGB에서 재현하도록 증류한 과거 실험의 F1은 0.1919, 낙하·인양 검출은 0/19였다. 기존 CPU 깊이 추출은 파일 읽기 포함 중앙값 1.40초, p95 2.35초였다. 어느 값도 L4 측정치가 아니다.

## 2. 개발 920장에서 새로 확인한 적용 범위

앞선 실험에서 고정한 두 분류기의 사진별 원장에서 중대성 4 정답 코드와 미탐을 대조했다. 전체 개발 사진 920장·29개 잠정 그룹 중 중대성 4 사진은 270장이다. 한 사진에 추락과 낙하·인양이 모두 있으면 합집합에서 한 번만 센다.

| 중대성 4 미탐 구분 | 해당 사진 | 추락 | 낙하·인양 | 둘 중 하나 이상 | 해당 그룹 |
|---|---:|---:|---:|---:|---:|
| 두 모델 모두 놓침 | 81 | 30 | 17 | 47 | 18 |
| 다중 후보만 놓침 | 28 | 11 | 2 | 12 | 7 |
| 단일 기준선만 놓침 | 15 | 4 | 4 | 8 | 6 |

두 모델이 놓친 81장 중 47장이 우선 검토할 두 위험을 포함한다. 이 수는 목표 위험의 빈도다. 검출 가능한 하중·난간이 실제로 보이는지, 보조 모델이 회복할 수 있는지는 별도 측정한다. 47장을 골라 성능을 발표하면 미탐이 과대표집되므로 모델 비교는 이미 고정한 개발 패널과 전체 OOF에서 하고, 이 명단은 원인 해석에 쓴다. [사진별 미탐 원장](../reports/phase1-severity4-paired-decision-20261126.csv)

## 4. 무엇을 보여주면 Qwen의 판정이 바뀌는가

| 순서 | 사전 고정 비교 | 판단할 내용 |
|---|---|---|
| 1. RGB 기준과 부분 확대 | 기존 Qwen 원본 전체 화면, 같은 계산 예산으로 전체 화면 재판독, 전체 화면+크기·위치 분포를 맞춘 무작위 확대, 전체 화면+검출한 사람·하중을 함께 담은 확대 1개. 출력 코드 상한·디코딩·추가 화면의 해상도와 토큰 예산을 고정한다. | 진짜 영역이 단순 확대나 한 번 더 본 효과를 넘어 실제 미탐을 회복하는가. 검출이 비면 전체 화면으로 복귀하고 빈 검출까지 분모에 넣는다. |
| 2. 깊이 | 같은 검출·자르기에 깊이 없음 / 해당 사진 V2 / 개발 훈련 그룹에서 가져온 교환 깊이를 비교한다. 출력 형식과 보조 정보 길이를 맞춘다. 사람과 하중 영역 안 깊이 백분위의 차이·분포 겹침을 사용하고 작은 영역이나 불분명한 경계는 관측 불가로 둔다. | 2차원 투영에서 머리 위로 겹쳐 보이지만 깊이상 떨어진 장면의 오경보를 줄이는가. 깊이는 실제 거리, 하중의 이동 방향 또는 보행자 충돌의 증명이 될 수 없다. |
| 3. 분할 | 같은 박스·해상도·재판독 횟수에서 박스만 / 실제 마스크 경계 / 면적을 맞춘 사각형 또는 교환 마스크를 비교한다. 원본 RGB와 주변 맥락을 항상 남긴다. | 작업자가 개구부 가장자리 안쪽에 있는지, 난간이 작업자와 단부 사이에 보이는지처럼 모양이 필요한 경우에만 마스크가 비용만큼 기여하는가. 안 보이는 난간을 난간 부재로 바꾸지 않는다. |
| 4. 조건부 실행과 훈련 전용 증류 | 검증된 보조 모델 하나를 전체 사진에 실행한 경우와, 첫 RGB 판독의 불확실성에 따라 일부만 재판독한 경우를 비교한다. 속도 부담이 크면 학습 때만 진짜 ROI를 감독 신호로 쓴 RGB LoRA와 동일 예산 RGB-only·교환 감독을 비교한다. | 동작 조건이 기존 완전 미탐 사진까지 포착하는가. 교사 출력을 RGB 학생이 실제로 재현하는가. 과거 32차원 깊이 증류 F1 0.1919를 고려해 성능을 실측한다. |

객체 이름에서 위험 코드를 자동 추가하면 위험이 없는 사진의 오경보가 늘 수 있다. 이전 개발 검증에서 빈 슬롯에 추가한 281개 코드 중 정답은 12개였다. 확인된 관측만 짧게 제시하고 Qwen이 얼굴·로프·고리·난간이 흐리거나 가려진 경우 기각할 수 있게 한다. 근거와 예방조치 문장을 쓸 때도 실제 거리·하중·체결 여부·측정하지 않은 위험 수준을 생성하는지 블라인드 비교한다. [빈 슬롯 복구 실험](../reports/phase1-severity4-paired-decision-20261126.md)

## 5. 채택과 패키징

- 동결한 16장 재판독에서 모델 로딩, 실제 ROI·마스크·깊이의 대응, 미검출 비율, 시간, 전체 분모에서 출력 유효성을 확인한다. 64장·23그룹에서 사진별 쌍체로 새 정답과 새 오탐을 기록한다. 작은 패널의 위험별 양성이 부족하면 결론을 유보한다. 보조 모델별 용어·임계값·자르기 폭·라우팅 규칙은 개발 훈련 분할 안에서만 정한다.
- 유망한 방법 하나만 920장·29개 개발 그룹의 기존 외측 5분할에 올린다. 동일 기반 모델의 RGB 판독과 비교해 공식 방식 Macro F1, 11종 고정 F1, 중대성 4 완전 미탐, 무위험 경보, 위험별 진양성·오양성, 근거 정확성을 함께 본다. Qwen 비교 기준은 같은 Qwen과 데이터 예산이다. Phase 1 분류기의 96/270 미탐은 별도 참고 비교다. 주최측 LoRA의 학습 노출이 불명인 진단을 독립 평가로 부풀리지 않는다. 125장 봉인본은 이번 실험에서 열지 않는다.
- 검출·분할 가중치가 작아도 Qwen의 추가 영상 토큰, 모델 로딩, 종속 휠, 최고 VRAM, 재판독 호출률이 전체 시간을 결정할 수 있다. 실제 후보의 새 ZIP 크기와 빈 캐시에서의 설치·모델별 로드·이미지별 p50/p95·총 소요를 기록한다. L4 24GB, 오프라인, ZIP 20 GB 이하, Public 200장 1,800초·Private 300장 3,600초를 검사한다. 기존 Phase 1의 5,816,690,916바이트 ZIP은 다른 아키텍처다. 새 후보의 L4 여유나 점수를 여기서 추정하지 않는다.
- 체크포인트 리비전, 라이선스, 전처리, 선택한 프롬프트와 거부 조건을 보관한다. 국내 로컬에서 개발 사진을 처리하고, 외부 AI로 학습용 가공 데이터를 생성하면 사용 모델·방법을 기록한다. 적법한 공개 외부 데이터는 실제 사용 시 12월 6일까지 신고하는 조건을 적용한다. [대회 규칙 및 채점 환경](https://hackathon.imaginationgroup.co.kr/kwater/#rules)

11월 26일 항목 #38의 기존 작업자에게 최초 검출 실측과 위의 대조 실험을 전달했다. 깊이·후보 모델의 과거 수치와 새로 집계한 47장까지가 현재 확인된 결과다. 새 객체 검출·분할 결합 방식의 K-water F1과 L4 비용은 측정 후 기록한다.

## 로컬 실측 기록

고정 16장 패널의 첫 수검 사진은 여섯 명사 모두 미검출이었다. 외측 훈련 측 교환 사진에서는 사람 4명이 검출됐고, 같은 박스와 SAM 2.1 마스크의 교집합/합집합 비율은 0.596이었다. 2,414픽셀 박스와 1,534픽셀 마스크를 대조한 값이다. [항목 38 실측표와 재현 명령](phase2-item38-measured-20261126.md)

동결 16장의 Grounding DINO Base 박스에서 SAM2.1 Tiny와 Large로 각각 6개의 실제 마스크를 얻었다. 조건부 호출의 CPU 처리 시간은 23.32초와 123.09초였다. 같은 원래 제공 풀에서 훈련측 교환 마스크를 확보한 사진은 6장이며, 각 모델에서 직사각형·실제·교환 마스크의 면적을 맞췄다. [대형 모델·마스크별 실측](phase2-large-model-execution-20261126.md)
