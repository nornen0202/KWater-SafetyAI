# 외부 자료 비교 실험 설계

2026-11-25. 아래 조건은 외부 영상 분류 성능을 계산하기 전에 정했다. 공식 대회 사진은 기존에 노출된 170장만 모델 실험에 사용한다. 전체 훈련 라벨에서는 변환기의 코드 보존 여부만 센다.

1. 참가자 라벨을 공식 8종 학습 변환기와 대회 11종 필드를 사용하는 후보 변환기에 각각 통과시킨다. 코드별 보존 수와 사라진 행을 센다. 11개 단일 위험, 복합 위험, 무위험 모의 출력은 공식 키트로 검사한다. 이 결과는 사진 인식 성능과 별도로 기록한다.
2. 국토안전관리원 샘플의 모든 이미지·라벨 쌍, 정규화 좌표, 클래스 범위와 중복을 검사한다. 71407의 사진·JSON 연결, 원본 영상 ID, 정상·비정상 쌍, 위험 유형을 확인한다. 장비 존재만으로 대회 위험을 부여하지 않는다.
3. FloodNet 원래 훈련·시험 분할을 유지한다. 128×128 최근접 샘플에서 침수 건물(1)·침수 도로(3) 비율 2% 이상을 양성으로, 두 코드가 0이며 마른 건물·도로·물·수영장(2,4,5,8)이 2% 이상인 장면을 음성으로 삼는다. 그 사이 장면은 제외한다. 고정 해시 순서로 훈련 클래스당 최대 96장, 시험 클래스당 최대 64장을 선택한다. 훈련과 시험 간 동일 이미지 또는 dHash 거리 4 이하를 제거한다. 비교군은 항상 음성, 고정 CLIP 문장 쌍, 훈련 양·음 중심점 유사도 차, 훈련 라벨을 섞은 중심점이다. 문장은 각각 `an aerial photograph of flooded roads and buildings after a flood`와 `an aerial photograph of dry passable roads and buildings`로 고정한다. 임곗값은 유사도 차 0, 순열 시드는 42다.
4. 이미 노출된 대회 사진 170장의 여섯 ID 접두사 교차검증에서 같은 사진, 분할, 근접중복 제외, CLIP 및 임곗값 0.5를 사용한다. A는 기존 선형 분류기, B는 KALIS의 실제 박스 crop을 클래스별로 평균한 벡터와의 유사도를 특징으로 추가한다. C는 A에 FloodNet의 중심점 침수 판정을 추가하고 D는 B에 같은 판정을 추가한다. 침수 위험이 검출되면 최대 세 위험 중 한 자리를 배정한다. 각 조건의 macro-F1, 무위험 오경보, 침수 오탐, 위험 사진 전체 누락을 공개한다. 접두사는 사고 식별자로 검증되지 않았고 이 표본에 침수 양성이 없으므로 이 결과로 침수 재현율, 독립 순위 또는 우승 가능성을 추정하지 않는다.
5. 71407에서 정상·비정상 및 원본 영상 ID를 이용할 수 있으면 별도 영상 단위 외부 검증을 추가한다. 같은 원본 영상의 프레임이 훈련·검증에 함께 들어가지 않게 한다. 부산 침수·고소작업은 파일 형식과 주석 단위를 확인해 직접 매핑 가능한 범위를 보고한다. 개선이 재현될 때 주최 측 신고 대상으로 선정한다.
