# AI-Hub 세 자료별 추가 비교

앞선 객체·침수 결과를 확인한 뒤, 개별 AI-Hub 자료를 평가하기 전에 정한 후속 탐색이다. 고정 CLIP 전체 화면 특징, 같은 170장·6개 묶음, L2 0.01, 250회 업데이트, 공통 임곗값 0.5, 최대 3종 출력을 적용한다.

1. 공식 자료만 사용한 기존 512차원 모델을 기준으로 둔다. 특징을 4개 늘릴 때 생기는 효과를 구별하기 위해 해당 훈련 묶음의 사진만으로 참조 중심점 4개를 만드는 516차원 대조 모델도 둔다.
2. 507은 정식 로프작업 훈련 분할의 원본 영상, 71407은 경량 샘플의 원본 영상, 71793은 파일명이 맞는 실제 CCTV의 촬영지·시간 폴더에서 뽑는다. 각 자료에서 원본 그룹당 사진 최대 1장, 서로 다른 현장을 우선하며 최대 12장을 고정 해시 순서로 선정한다. 공식 탐색 170장 및 이미 뽑은 같은 자료의 dHash 거리 4 이하는 제외한다. 실제 최소 확보 수로 세 조건의 참조 사진 수를 맞춘다. 참조 사진에서 구한 중심점과의 유사도 4개를 추가한다. 해당 출처의 주석을 대회 위험으로 변환하지 않는 관찰 특징 실험이다.
3. 71407에만 별도의 약한 지도학습 비교를 둔다. ‘추락·전도·협착·낙하·화재’라는 제공자 구분에 연결되는 코드 하나의 정답만 사용한다. 다른 코드는 미확인이다. 같은 원본 영상은 하나만 쓰고 참조 사진과 같은 중복 기준을 적용한다. 위험별로 정상·비정상을 같은 수로 뽑는다. 대회 훈련 사진을 같은 수·같은 양음 비율로 재표집해 붙인 대조군, 외부 라벨을 붙인 군, 외부 라벨을 섞은 군의 학습 행 수와 업데이트 수를 맞춘다. 해당 묶음에 대회 양·음성이 모두 있는 코드만 바꾼다. 507과 71793은 직접 정답 비교를 보류한다.
4. 결과 파일에 조건별 11종 TP·FP·FN, macro-F1, 무위험 오경보, 위험 전체 누락을 모두 남긴다. 독립 사건 점수 또는 대회 순위로 외삽하지 않는다.

### 재현

프로젝트 루트에서 `$env:OPENBLAS_NUM_THREADS='1'` 설정 후 `python -m kwater_lab.aihub_ablation`을 실행한다. 공개할 수 있는 집계는 `results/aihub_ablation.json`에 저장한다. 각 출처의 특징은 원본과 함께 G:의 `data/external/aihub`에 보관한다. 공급기관은 한국지능정보사회진흥원(NIA) AI-Hub다. [고소작업](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=507) · [건설 현장](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=71407) · [부산 침수](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=71793)
