# SafeGround v6 외부 자산 신고 초안

**신고 마감은 2026년 12월 6일 23:59 KST.** 운영진이 공개한 공지와 규칙을 11월 28일 23:39 KST에 확인했다. 공개 외부 데이터를 학습에 쓰려면 `내 참가 → 외부 데이터 신고`에서 데이터별로 한 건씩 등록한다. 이미 이메일로 접수한 건은 중복 등록할 필요가 없다. ZIP의 `assets.json`은 모델·데이터·라이브러리와 시드를 적는 별도 제출 파일이다. 공개 규칙은 기반 모델의 이름·버전·라이선스와 외부 AI로 만든 학습 라벨·설명의 모델·방법을 결과보고서에 공개하도록 안내한다. 모델만 사용하는 경우의 별도 포털 등록에 관해서는 팀 계정의 안내를 확인한다. [운영진 신고 공지](https://hackathon.imaginationgroup.co.kr/kwater/api/notices) · [공식 규칙·제출 안내, 공개 원문 리비전 94](https://hackathon.imaginationgroup.co.kr/kwater/api/report) · [팀 신고 화면](https://hackathon.imaginationgroup.co.kr/kwater/#my/data)

## 팀 계정에서 확정할 항목

1. **데이터 접수 확인.** 로그인한 팀의 신고 목록에서 71407을 포함해 실제 사용한 데이터의 접수 여부와 이메일 제출 표시를 확인한다. 새 신고에는 이름, 제공처, URL, 라이선스·조건, 무료 취득 여부, 사용 목적과 실제 이미지 수, 직접 라벨링 여부를 기재한다. AI가 데이터를 만든 경우 해당 모델과 생성 방식을 기록한다. 개발 평가에만 쓴 외부 자료가 문턱이나 후보 선택에 관여한 경우와 공식 학습 사진의 교사 생성 주석을 별도 신고할지 화면 안내를 확인한다. [운영진 공개 안내](https://hackathon.imaginationgroup.co.kr/kwater/api/report) · [팀 신고 화면](https://hackathon.imaginationgroup.co.kr/kwater/#my/data)
2. **후보 계보 동결.** BF16 또는 FP8을 선정하고 실제 적재본, BF16 훈련 기반, 어댑터 지문, 프롬프트 버전, 법령 사례 범위와 종속 라이브러리를 대조한다. 혼합·현행 순수 판독의 OOF 타워는 간접 사용으로 표기한다. 하이브리드는 두 타워의 탑재와 변환 지문도 추가한다. 4B 재판독기 또는 27B 교사를 채택하면 정확한 버전·역할·학습 반영 수를 추가한다. [Stage 1](../reports/safeground-v6-stage1-20261128.md) · [공식 ZIP 요건](https://hackathon.imaginationgroup.co.kr/kwater/#submission)
3. **27B 분기 확인.** 기존 GGUF를 쓰면 검증된 본체·BF16 프로젝터 파일 두 개를 고정한다. 새 QLoRA 병합과 재양자화를 선정하면 네이티브 원본·어댑터·변환기 버전·양자화 설정·실제 보정 자산과 새 두 파일의 해시를 기록한다. 기존 GGUF의 변환 당시 정확한 네이티브 커밋이나 보정 코퍼스 명세는 배포처의 공개 계보에서 확인되지 않았다. [변환 배포처](https://huggingface.co/unsloth/Qwen3.8-27B-GGUF/tree/4af51b3542f775b0a8e4b310bfb3f17e01c306c9)
4. **실제 최종 ZIP 대조.** ZIP의 `assets.json`과 파일 지문, 팀 접수 내역, 결과보고서를 서로 맞춘다. 훈련 전용·검증 전용의 역할도 보존한다. 주최측 학습 사진·주석과 동봉 법령은 대회 제공 자료 항목으로 기록하고 팀 제출 범위에서 관리한다. [공식 규칙](https://hackathon.imaginationgroup.co.kr/kwater/#rules) · [공식 제출 방법](https://hackathon.imaginationgroup.co.kr/kwater/#submission)
