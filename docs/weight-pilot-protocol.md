# 탐색 실험 W1 · 분류기 가중치 편집과 시각 사례 검색

최초 실행 전에 다음 조건을 고정했다. 이전 탐색 점수와 공개 사진 오류를 본 뒤 만든 가설이다. 이번 결과로 독립 사건 성능이나 대회 점수를 추정하지 않는다.

- **대상**은 이미 노출한 170장, 6개 ID 접두사 묶음이다. 기존 전체화면 512차원 CLIP 특징, 11개 sigmoid 출력, 상한 3개, 기존 정규화·학습률 규칙·250회 반복을 유지한다. 검증 묶음과 동일 또는 dHash 거리 4 이하인 학습 사진은 제외한다.
- **W0**는 기존 선형 분류기다. **W1**은 걸림과 추락의 분류기 열벡터를 읽어 상대 열과의 내적이 양수일 때 그 축으로의 투영 성분을 각 열에서 절반 제거한다. 두 수정은 원본에서 동시에 계산한다. 입력을 표준화한 좌표계의 절편을 유지한다. 두 유형에 공통으로 쓰이는 시각 단서가 혼동을 만든다는 가설이며, 두 위험이 함께 있는 사진에서는 손해를 볼 수 있다. 양의 성분이 없으면 편집량은 0이다.
- **대조 편집**은 같은 열에 W1과 정확히 같은 크기의 무작위 변화를 준다. 방향은 상대 열에 직교하도록 만들고 난수 시드는 42로 고정한다. 새로운 사진이나 모델 출력을 보고 방향을 고르지 않는다.
- **검색 비교**는 각 검증 사진에 대해 학습 묶음의 코사인 유사도 상위 8장을 찾고, 가중치 `exp(20 × (유사도 − 최댓값))`로 11개 라벨의 가중평균을 계산한다. 검색 단독과 W0 확률을 1:1로 평균한 조합을 평가한다. Tip-Adapter에서 착안한 다중라벨 변형이다.
- **평가**는 각 방법의 고정 임계값 0.5와, 바깥 검증 묶음을 제외하고 안쪽 묶음에서만 고른 공통 임계값을 모두 보고한다. 주 비교는 보정된 W1과 보정된 W0의 Macro F1 차이다. 무위험 사진 오경보, 위험 사진 완전 미탐, 두 유형 동시 정답 사진의 동시 검출, 묶음별 차이도 기록한다. 시드 42로 여섯 묶음을 2,000회 재표집한 구간은 탐색 민감도다.
- **해석 기준**은 같은 조건에서 W1이 원본과 무작위 편집을 모두 앞서는지, 오경보와 완전 미탐이 얼마나 바뀌는지다. 다음 후보 선정에는 새 사건 묶음에서의 재현이 필요하다.
- **공식 어댑터**는 별도로 읽기 전용 분석한다. 각 층·모듈의 저랭크 업데이트 `(α/r)BA`의 특이값을 계산해 업데이트 에너지의 집중도를 본다. 이 값은 압축·보간 실험의 대상을 좁혀 주며, 정확도 측정은 별도로 필요하다.

## 같은 Qwen 모델에서 수행하는 진폭 실험

여섯 접두사마다 `sha256("kwater-scale-a-v1/" + sample_id)` 순서의 첫 3장, 총 18장을 선택한다. 선택에는 라벨을 사용하지 않는다. 같은 GPU 메모리에 적재된 공식 본체와 LoRA에 대해 기본 배율 1.00과 0.75를 고정 순서로 비교한다. 전처리·원본 프롬프트·seed 42·greedy·최대 토큰 900·배치 1을 유지한다. 연구 실행기에서만 모든 활성 LoRA 층의 잔차 배율을 잠시 바꾸고 복원한다.

코드 집합·Macro F1·미관측 오경보·완전 미탐·파싱 실패를 측정한다. 입력 행의 ID는 익명화하고 모델에는 이미지와 고정 프롬프트만 전달한다. 법령 검색이나 LLM 심사 점수를 측정하지 않는다. 배포 어댑터가 학습 자료를 이미 사용했으므로 결과는 배율 변화의 **동작 진단**으로만 쓰며 제출 후보 선정에는 새로운 사건 검증을 요구한다.

## 검색 결합의 오경보 후속 실험

1:1 검색 결합에서 무위험 사진 66장 중 경보가 31장에서 37장으로 늘어난 결과를 본 뒤 정한 추가 가설이다. 같은 사진과 같은 두 모델에서, 각 모델의 안쪽 교차검증 오경보율을 20% 이하로 제한하고 그 안에서 Macro F1을 최대화한다. 임계값 후보, 동점 규칙과 전부 보류하는 선택지는 기존 `calibrate_fpr20`을 그대로 사용한다. 바깥 접두사 하나의 라벨도 선택에 쓰지 않는다. 주 비교는 동일한 제약을 건 기존 분류기 대 검색 결합이다. 두 조건의 위험 유형별 F1·오경보·완전 미탐과 접두사 재표집 구간을 보고한다. 여섯 접두사와 170장을 재사용하므로 후속 확인은 새 사건에서 해야 한다.
