## 손실과 갱신

학습기는 먼저 각 예제의 가중 토큰 교차 엔트로피를 유효 가중치 합으로 나눈다. 그 예제의 손실을 현재 그룹 크기로 나눠 역전파한다. 마지막 1건의 손실 계수 1은 같은 예제를 늘 고정 분모 16으로 나눴을 때의 1/16보다 16배다. 스텝 85의 로그 손실 .6129는 그룹의 원래 예제 평균이며 같은 forward에서 고정 분모로 바꿔도 이 표시 자체는 그대로다.

`clip_grad_norm_`은 **클리핑 전** 전역 L2 노름을 반환하고 실제 기울기는 L2 1.0으로 제한한다. 스텝 80–84는 .5504, .6562, .5713, .5742, .6332로 1 이하다. 스텝 85의 2.2130은 클리핑 뒤 약 1.0이며 동일 원시 기울기를 16으로 나누면 .1383으로, 비율은 약 7.23이다. 스텝 170도 2.1823에서 약 1.0으로 클리핑되며 동일 기울기의 고정 분모 가정은 .1364다. 스텝 85의 적용 학습률은 7.7498×10⁻⁵, 스텝 170은 1.3326×10⁻⁸이다. AdamW는 누적된 일·이차 모멘트, 편향 보정, 파라미터별 분모 및 분리 weight decay를 적용하므로 이 노름 비율로 파라미터 갱신 배율을 구할 수 없다. [학습기](../kwater_lab/vlm_11code.py#L797)

기존 L4 개발 패널의 7차→8차 후보 심각도 4 완전 미탐은 22/68→34/68이며, 맞춘 장면을 잃은 15건과 새로 맞춘 3건의 순차이다. 6차→7차의 위험→무위험 12장과 분모 및 정의가 다르다. 7차와 8차 후보는 에폭과 검증기 정책이 함께 다르고 모두 전량 훈련에 노출된 사진을 판독했다. 5번의 갱신이 섞인 checkpoint 80→85 또는 두 패키지 비교만으로 마지막 1건이 만든 미탐 수를 추정할 수 없다. ## 분리 대조 절차

원본 checkpoint-80과 epoch-1(85), epoch-2(170)에 AdamW 520슬롯의 모멘트와 scheduler·CPU/CUDA/에폭 RNG가 있다. 각 파일에서 3개 슬롯의 스텝 스칼라를 읽어 80/85/170을 확인했다. 원본 84는 없다. 정답과 현장 그룹으로 결정한 동결 실측 계획은 200장 패널 안에서 하나의 현장에 한 장씩 정상·심각도 4·그 외 위험 각 10장이다. 순서는 고정 해시이며 다른 출력은 선정에 쓰지 않았다. 30장은 모두 전량 학습 노출 진단이고 정상 10장의 오경보 한 건은 10%p다.

```powershell
python -B -m kwater_lab.sub78_tail_replay prepare
python -B -m kwater_lab.sub78_tail_replay prefix84
python -B -m kwater_lab.sub78_tail_replay native85
python -B -m kwater_lab.sub78_tail_replay fixed85
python -B -m kwater_lab.sub78_tail_replay infer
python -B -m kwater_lab.sub78_tail_replay score
```

1. `prepare`와 `score`는 CPU 전용이다. 중간 네 단계는 GPU가 비면 순서대로 실행한다. 원래 학습기를 읽어 별도 프로세스에서 같은 함수의 마지막 배치 분모만 선택하며 원본 소스·훈련·ZIP은 그대로 둔다.
2. `prefix84`는 checkpoint-80에서 원래 분모로 81–84를 한 번만 재생한다. 두 팔이 같은 84 어댑터·optimizer·scheduler·RNG 상태에서 85를 한 번씩 수행한다. 각 팔의 출발 상태 SHA가 일치해야 한다.
3. 원래 스텝 85와 기존 분모 재현의 가중치 SHA, 스텝 로그 및 동일 BF16 30장 출력 일치를 별도로 확인한다. 정확 재현이 실패하면 변경 후 팔과 기존 분모 재생 팔의 차이는 해당 재생의 조건부 효과로 해석한다.
4. BF16 배치2 30장으로 정상 오경보, 양방향 위험·정상 전환, 심각도 4 코드 일치의 획득·소실을 센다. 이 CPU 원장에는 실제 업데이트 결과 또는 재생 성능이 없다. 기존 스텝 81–84의 합계는 388.88초이며 학습 재시작·저장·생성의 추가 시간은 별도다.
