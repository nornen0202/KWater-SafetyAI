# 전체 사진의 상대 깊이와 추락·인양 위험 탐색

대회 사진에 깊이 모델을 실행하기 전에 정한 비교다. 사진은 기존 노출 명단의 170장 전부를 사용한다. 공식 사건 보류셋과 다른 GPU 실험에는 접근하지 않는다.

## 대회 사진 비교

1. 기준선은 앞서 지문을 검증한 전체 화면 CLIP 512개 특징이다. 6개 ID 접두사 중 하나씩 검증에 쓰고, 해당 사진의 동일·근접 중복을 학습에서 뺀다. 접두사의 사건 독립성은 확인되지 않았다.
2. 같은 RGB 장면에서 밝기, 2차원 밝기 경계, 단안 상대 깊이를 계산한다. 화면 전체의 종횡비를 유지해 518×518에 맞추고, 분석할 때 여백을 제거한다. 각 지도를 64×64로 줄이고 2·98백분위수로 영상 안에서 정규화한다. 4×4 격자에서 값의 중앙값과 기울기 크기의 평균을 구해 각각 같은 32개 특징을 만든다.
3. 전체 사진 CLIP, CLIP+밝기, CLIP+경계, CLIP+동일 사진 깊이, CLIP+다른 사진 깊이를 비교한다. 학습 대조군은 다른 접두사·다른 사진의 깊이를 일대일 교환한다. 검증 대조군은 그 바깥 분할의 학습 사진에서만 깊이를 가져온다. 동일·근접 중복을 대조군으로 사용하지 않는다. 분류기는 동일한 선형 11종 모델, L2 0.01, 250회, 공통 임곗값 0.5, 최대 3개 코드다.
4. 11종 TP·FP·FN 및 macro-F1 외에 추락·낙하/인양 각각의 양성 수, 전체 음성 수, 무위험 사진에 낸 해당 경보 수, 무위험 사진에 낸 모든 경보 수를 기록한다. 깊이가 만든 개선 여부는 같은 차원의 경계·다른 사진 깊이와 함께 해석한다. 정확한 높이·거리, 난간 유무, 사람이 하중 아래에 있는지 여부는 상대 깊이만으로 결정할 수 없다.

## 첫 측정 뒤 추가한 대조 실험

같은 사진 깊이와 첫 대조군의 macro-F1 차이가 0.0061이어서, 깊이 지도를 어느 사진과 바꾸느냐에 따른 편차를 확인한다. 추가 실행 전에 1~20번의 고정된 교환 순서와 기존 여섯 분할을 정했다. 각 실행에서 기존 조건과 같은 방법으로 잘못 짝지은 깊이로 학습과 검증을 모두 수행한다. 20회의 중앙값·범위 및 같은 사진 깊이 점수에 도달한 횟수를 공개한다. 이 횟수는 선택한 대조 방식의 민감도를 보여 주며 독립 사건에 대한 유의확률을 제공하지 않는다.
