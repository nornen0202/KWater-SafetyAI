# 공식 탐색 사진의 추락·인양 상태 비교

기존 탐색 사진 170장이 최종 보류 제외 182장에 포함됨을 확인했다. 그 안에서 Codex가 중립 번호로 표시한 전체 사진 50장을 모델 검토했다. 사람 검토는 0건이다. 신규 사진 노출은 0장이다.

| 위험 | 후보·모델 검토 | 상태 비교에 사용 가능 | 상태 미확정 | 사건 관계 미확정 |
|---|---:|---:|---:|---:|
| 높이차 추락 | 6쌍 | 1쌍 | 5쌍 | 6쌍 |
| 낙하·비래·인양물 맞음 | 20쌍 | 2쌍 | 18쌍 | 20쌍 |
| 합계 | 26쌍 | 3쌍 | 23쌍 | 26쌍 |

추락에서는 높은 비계관 위 발의 노출과 지주 아래에 연속 바닥이 보이는 상태의 대비가 1쌍이었다. 인양에서는 펼친 줄과 인근 작업자 대 접힌 붐이 1쌍, 지게차의 들린 적재 용기 대 비어 있는 낮은 포크가 1쌍이었다. 마지막 지게차 쌍은 이미 판독한 두 쌍의 장면을 사후에 재조합했다. 세 쌍의 용도는 후속 오류 분석에서 관측 근거와 판독을 대조하는 것이다. 독립 성능 평가는 별도 표본이 필요하다.

## 선정과 판독

1. 고정된 탐색 사진의 공식 코드 양성·음성 사이에서 기존 CLIP과 SigLIP2-384 전체 프레임 벡터의 코사인 유사도 평균을 계산했다. 두 코드에서 번갈아 이전 쌍과 사진이 겹치지 않는 가장 가까운 후보를 각각 6쌍 골랐다. 동률에서는 고정된 식별자 순서를 사용했다.
2. 중립 번호 순으로 사진 전체를 비율을 유지해 표시했다. 사진에 보이는 인물과 지지면·장비·물체·통행 공간, 가림과 시야 한계를 먼저 적었다. 관찰을 고정한 뒤 위험 코드와 양성·음성 부호, 두 사진의 대응 관계를 확인했다. 1차 인양 후보에서 뚜렷한 대비가 없어, 기존 170장 안의 나머지 인양 양성 13장도 유사 음성과 같은 절차로 판독했다. 자동 후보는 총 25쌍이다. 사후 재조합 1쌍은 별도로 집계한다.
3. 추락은 사진에서 작업자가 설 위치와 아래쪽 공간이 보이는지, 발판·개구부·난간의 위치가 그 노출을 어떻게 바꾸는지 비교한다. 인양은 하중이 받쳐져 있거나 연결·들려 있는 상태, 사람이 그 주변에서 차지하는 위치, 장비의 작동 구성과 차단 구획을 비교한다. 양쪽에서 대응하는 상태를 볼 수 있어야 채택한다. 사진 밖 방호와 실제 하중 결속, 시점 간 움직임은 추정하지 않는다.
4. 촬영 방향이나 가림 때문에 한쪽 상태를 읽을 수 없거나, 서로 다른 장비·잔해의 외형만 비슷하면 미확정으로 둔다. 상태 채택과 사건 관계는 개별 항목이다. 사건 출처를 확인할 근거가 없어 이번 쌍의 사건 관계는 모두 미확정이다.

## 재현

탐색 사진과 캐시를 갖춘 프로젝트 루트에서 실행한다. `prepare`는 기존 판독을 보호하므로 이미 생성된 패널은 덮어쓰지 않는다.

```powershell
python -m kwater_lab.official_state_contrasts prepare
# 첫 24장 관찰을 로컬 blind-review.json에 고정한다.
python -m kwater_lab.official_state_contrasts extend-lifting
# 추가 전체 사진을 가리고 판독한 뒤 판정과 사후 재조합을 로컬에 기록한다.
python -m kwater_lab.official_state_contrasts summarize
```

원본 복사본, 중립 번호판, 후보·라벨 대응표, 개별 관찰, 사건 판정 사유는 로컬 `data/state-pairs/`에 보관한다. 집계 명령은 고정 캐시로 등록된 자동 후보를 재선정하고, 사후 쌍이 동일 코드의 기존 판독 사진만 사용했는지 확인한다. [집계 결과](../results/official_state_contrasts.json)
