# Fold 0 교차 장면과 그룹 제외 민감도

눈가림 검토 26쌍에서 기존 훈련 그룹과 Fold 0 검증 그룹 사이의 동일 현장·장면 링크 3개를 확인했다. **주평가 216장·36그룹은 그대로 유지**한다. 별도 민감도는 확인 링크가 걸린 Fold 0 그룹 2개의 182장을 모든 비교 조건에서 함께 제외한다. **181장은 하나의 기존 추정 그룹에 속한 사진 수**다. 직접 확인한 교차 장면은 이 그룹에서 두 쌍이며 나머지 구성원의 사건 정체는 이 검토로 확정되지 않았다.

## 시각 검토와 이전 그룹의 형성

첫 검토 8쌍과 두 번째 검토 18쌍은 사진만 보고 판정했다. 두 번째 검토는 기존 Fold 0 교차 미해결 후보 중 이미 검토한 unordered 그룹쌍을 빼고, 남은 255개 사진쌍·79개 그룹쌍에서 코사인 상위 18개를 골랐다. 코사인 범위는 0.9506~0.8208이다. 확인 링크는 철거 장면의 상이한 축척, 흙막이 굴착 현장의 다른 시점, 비계·크레인 현장의 다른 시점에서 관찰했다. 상위 후보를 우선 확인했으므로 확인 건수 비율로 나머지 쌍이나 전체 개발 데이터의 누수율을 추정할 수 없다. [연속 검토표 재현](../kwater_lab/crosssplit_visual_review.py)

추가 후보 한 쌍의 CPU 점검에서 SIFT 키포인트는 양쪽 각각 2,719개와 2,703개였다. 상호 Lowe 비율 0.65/0.72/0.80에서 대응은 1/4/12개다. 0.72에서는 호모그래피 최소 추정 수인 4개가 맞고, 0.80에서는 12개 중 6개가 맞았다. 후자의 대응 볼록껍질 면적은 양쪽 9.7%와 5.6%다. 반복 구조가 있는 두 사진에서 장소를 확정할 정도의 지지는 부족해 보류했다. 고정한 세 링크의 마스크는 그대로 유지했다.

그룹의 기존 생성 규칙만 재생했고 개발 966장의 192개 그룹 구성과 정확히 일치했다. 성공한 합병은 접두사 767개, 이미 격리 판정이 기록된 기하 링크 2개, 자동 ORB/RANSAC 임계 통과 링크 4개, dHash 거리 6 이하 1개다. 정확 픽셀 해시 일치와 근접 ID용 dHash 완화 규칙으로 성공한 합병은 0개다. 최대 Fold 0 그룹의 181장은 모두 S_C다. 초기 접두사가 만든 127장과 54장 두 묶음이 이전 쌍 목록의 자동 임계 통과 한 건으로 합쳐졌다. 이 링크는 47 inliers, inlier 비율 0.7015이며 이전 판정 표기는 미해결이었다. 원본 두 컷을 직접 확인해 노란색·적색 철골, 임시 벽체와 금속 지붕의 배치가 일치하고 한 컷이 다른 컷의 일부를 잘라낸 변형임을 확인했다. 시각적 일치가 입증된 범위는 이 두 컷이다. 두 접두사의 나머지 사진에 대한 현장 확인은 남아 있다. 이번에 확인한 큰 그룹 관련 교차 두 쌍의 Fold 0 사진은 모두 127장 접두사 쪽이다. 향후 분할에는 사람이 확인한 실제 사진 연결을 우선 제약으로 보존한다. 기존 그룹 전체를 그대로 연결하면 크기 31장과 229장의 두 구성요소가 생긴다. 특히 229장은 127·54장의 접두사 묶음과 기존 한 기하 링크에 좌우된다. 현장 식별이나 셔터 순서로 검증 가능한 하위 묶음이 확인되기 전에는 229장을 새 분할의 확정 사건으로 고정하지 않는다. 이번 작업에서 새 할당을 실행하지 않았다.

## 주평가와 민감도의 해석

| 비교 범위 | 사진 / 그룹 | 해석 |
|---|---:|---|
| 주평가 | 216 / 36 | 동결된 원래 Fold 0. 그룹 단위 쌍체 부트스트랩 |
| 최대 단일 그룹 | 181 / 1 | 사진 비중 83.8%, 별도 기술 통계. 단일 그룹 신뢰구간 없음 |
| 최대 그룹 이외 | 35 / 35 | 주평가 사진의 16.2% |
| 확인 링크가 있는 두 그룹 제외 | 34 / 34 | 평가 자료 구성에 민감한 별도 진단 |

민감도의 34장은 위험 28장과 위험 미관측 6장이다. 위험 코드의 지원은 기타 13, 화재·폭발 7, 미끄러짐·걸림 7, 감전 6, 화학물질 3, 추락 1이며 다중 라벨을 포함한다. 나머지 5개 코드의 정답 지지는 0이고 S_C 출처가 모두 빠졌다. 따라서 결과가 달라지더라도 기존 교차 장면 제거 효과와 표본 구성 변화가 함께 작용한다. 34장을 독립 검증 목표나 대회 대표 표본으로 확대 해석하지 않는다.

민감도 비교기는 공식·후보·선택적 하이브리드 원출력이 각각 동일한 원래 216장을 중복 없이 포함하는지 먼저 검사한다. 이후에만 확정 마스크를 세 조건에 같이 적용한다. 제거하지 않은 그룹에서 2,000회 쌍체 그룹 bootstrap과 활성 F1, 8개 고정 코드 평균, 위험 미관측 오경보, 중대성 4 완전 미탐을 집계한다. 최대 그룹의 지표는 신뢰구간 없이 별도 저장한다. 집계 JSON은 입력과 마스크의 SHA-256, 그룹·사진 수와 지표만 담으며 평가 ID를 담지 않는다. 실제 Fold 0 생성 결과가 완성된 뒤 해당 원출력을 연결해 실행한다.
