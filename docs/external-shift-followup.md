# 침수 오경보의 후속 재검증

첫 비교에서 FloodNet 중심점의 대회 탐색 사진 침수 오탐은 48/170이었다. 이 결과를 본 뒤 다음 계산을 정했다. 최초 실험과 구분하여 해석한다.

각 외부 접두사 평가 묶음을 뺀 대회 훈련 사진 중 침수 음성만 사용한다. 훈련 사진의 침수 중심점 점수 95백분위수(관측값 올림)와 0 중 큰 값을 임곗값으로 고정한다. 평가 묶음에서는 점수가 그 값을 엄격히 초과해야 침수를 추가한다. 원래 분류기의 11종 판정과 최대 3개 출력 규칙은 그대로 적용한다. 각 임곗값을 동일한 FloodNet 시험 114장에도 적용해 양성 재현율 범위를 센다. 이 시험에서는 대회 침수 양성에 대한 효과를 측정할 수 없다.

공개 시험의 대조군은 모두 양성 예측과 훈련 라벨 1,000회 순열(시드 173)을 추가한다. 순열 분포, 동일 폭의 95% Wilson 구간은 촬영 사건의 독립성을 보장하지 않는 기술 통계로 보고한다.
