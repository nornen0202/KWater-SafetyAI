# 동결한 Fold0 재판독 A/B의 공통 평가

두 arm은 각각 완료된 체크포인트와 동일한 공식 216장 출력을 사용한다. 시각 입력, 위험 코드, 순서가 같은 동결 후보 102개를 완주한 경우에만 비교한다. 평가기는 두 arm의 체크포인트·설정·프롬프트와 BF16 런타임 지문을 확인하고, 각 원응답을 같은 엄격한 파서로 다시 해석한다. 불완전한 응답은 올바른 기각으로 세지 않는다. [실행 및 학습 확인](../kwater_lab/paired_verifier_ab.py) · [공통 평가기](../kwater_lab/paired_verifier_ab_score.py)

승인한 제안만 공식 포맷의 빈 위험 슬롯에 추가한다. 기존 위험 코드와 근거·조치·등급·인용은 그대로 유지하고, 바뀌지 않은 사진은 공식 JSONL의 행을 바이트 그대로 사용한다. 새 법령 인용은 보호 그룹을 제외한 Fold 1–3의 동일한 허용 사례 풀에서 찾아 새로 승인한 위험에만 붙인다. 무위험 판정에서 위험이 추가된 경우 공식 스키마에 맞춰 새 행의 상태와 장면 필드를 조정하며 원래 행은 로컬 원본에 남는다. A와 B 각각 공식 키트의 216/216 검사 통과가 필요하다.

후보 코드의 정답 주석 존재 여부로 승인 TP·FP를 구분하고 모호하거나 형식을 위반한 모델 응답을 별도 집계한다. 후보 102개를 사람이 별도로 모호성 판정한 정답은 없으므로 그 항목은 미측정으로 둔다. 사진 단위에서는 정상 오경보, 중대성 4 위험의 완전 미탐과 코드 미탐, 활성 코드 Macro-F1을 계산한다. 공식↔A, 공식↔B, A↔B의 F1 차이는 전체 36사건 쌍체 bootstrap과 확정 그룹 제외 후 34장·34그룹에서 각각 계산한다. 조건부 승인 정확도는 후보가 있는 사건들을 단위로 비교한다. 34장 민감도는 전체 집계와 함께 해석한다.

평가는 승인된 계약과 정확히 일치하는 두 arm 결과가 나온 뒤 `paired_verifier_ab`의 `score` 단계에서 실행한다. 사진별 원응답과 두 출력 파일은 로컬 `data/`에 저장하고, 집계에는 평가 지문·통계만 남긴다. CPU 회귀 검사는 실제 A/B 승인율·정확도·시간 측정을 대체하지 않는다.

승인된 학습 대조가 1–3쌍이면 기술적인 기준 충족 여부를 보여도 탐색 결과로 표기한다. 승격 판단을 보류하고 새 사건에서 재현을 확인한다.
