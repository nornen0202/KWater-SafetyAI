# 루프 트랜스포머와 현장 위험 판독

2026년 11월 25일. 연구 질문은 전체 사진에서 뽑은 시각 단서를 같은 가중치로 한 번 더 읽으면 추락·인양물 위험의 순위와 최종 경보가 개선되는가이다. 한 번의 시각 인코딩 뒤에 분류 블록을 반복한다. 동일 프롬프트 재생성은 기존 프롬프트 실험에서 다룬다.

데이터가 제한된 BabyLM 연구는 같은 추론 연산량의 반복 언어 모델에서 문법 평가가 개선됐지만, 이미지당 고정 벡터 하나를 더한 멀티모달 조건에서 생긴 문법 점수 하락은 반복으로 해소되지 않았다고 보고했다. 사진에 담긴 관계를 다시 읽을 수 있도록 이번 탐색에는 36개 공간 토큰을 남겼다. BabyLM의 측정 대상은 언어 문법으로, 현장 위험 판독과 과제가 다르다. [Loop Before You Leap](https://arxiv.org/abs/2611.06206)

## 고정한 탐색 실험

- 기존 노출 170장, 미확정 ID 접두사 6묶음이다. 매번 한 묶음의 사진을 예측하며 같은 화소·근접 해시 후보를 학습에서 배제한다. 운영진 학습 어댑터를 사용하지 않는다.
- 전체 사진을 여백과 함께 384픽셀로 처리한다. 고정된 SigLIP 2의 24×24 패치 특징을 인접한 4×4씩 평균해 36개 시각 토큰을 만든다. 각 토큰을 데이터와 독립적인 고정 난수 행렬로 24차원에 투영한다. 모든 사진의 원래 풀링 벡터가 기존 캐시와 일치해야 진행한다.
- 11개 코드별 질의에 같은 사진의 시각 토큰을 제공한다. 단일 헤드 교차 주의, 잔차 연결, 2층 ReLU 피드포워드로 구성한 블록을 ① 1회, ② 같은 가중치로 2회, ③ 별도 가중치로 2회 적용한다. ①과 ②의 파라미터 수가 같고 ②와 ③의 블록 실행 횟수가 같다. ②와 ③은 학습 전 함수가 같다. ②의 첫 단계 출력도 별도 측정한다.
- 시드 42와 137을 각각 보고한다. 매 단계에 해당 학습 분할 전체를 사용하며 Adam 32회, 학습률 0.003, 고정 경보 임곗값 0.30, 사진당 최대 3코드를 적용한다. 해당 학습 묶음에 양성이 없는 코드의 출력을 0으로 고정한다. 1차 지표는 정답 코드의 임곗값 적용 전 상위 3위 적중 수다. Macro F1, 위험 미관측 오경보, 추락·인양물 적중 및 기존 768차원 전체 사진 선형 분류기도 함께 비교한다.
- 시각 인코더는 CPU 1스레드로 처리한다. 분류기 시간은 예열 후 사진 1장 단위로 재며 인코더·생성기·설치 시간을 제외한다. 패치 특징과 사진별 점수는 실행 중 메모리에서 다룬다. 저장 결과는 집계, 조회 원본의 해시, 소요 시간이다.

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$env:MKL_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
python -B -m unittest discover -s tests -p test_loop_head.py -v
python -B -m kwater_lab.loop_pilot
```

## 170장 실측

복수 값은 시드 42 / 137 순서다. 정답 위험은 총 149건, 위험 미관측 사진은 66장, 추락 양성은 34건, 인양·낙하물 양성은 19건이다. 임곗값은 모두 0.30이다. [집계와 재현용 해시](../results/loop_pilot.json)

| 조건 | 학습 파라미터 | 정답 상위 3위 | Macro F1 | 미관측 오경보 | 추락 최종 적중 | 인양 최종 적중 |
|---|---:|---:|---:|---:|---:|---:|
| 학습셋 코드 빈도만 사용한 사후 대조 | — | 125 | 0.0708 | 66 | 0 | 0 |
| 전체 사진 768차원 선형 분류기 | — | 119 | 0.2313 | 21 | 7 | 4 |
| 패치 블록 1회 | 4,571 | 125 / 125 | 0.1331 / 0.1336 | 30 / 26 | 1 / 2 | 0 / 0 |
| 같은 블록 2회 | 4,571 | 120 / 119 | 0.1281 / 0.1655 | 31 / 23 | 0 / 9 | 0 / 0 |
| 별도 블록 2회 | 8,603 | 121 / 119 | 0.1280 / 0.1665 | 31 / 27 | 0 / 10 | 0 / 0 |

코드 빈도만으로 상위 3위 125건을 맞힌 이유는 해당 세 코드의 양성 수가 추락 34건, 걸림 56건, 기타 35건이기 때문이다. 공유 블록을 두 번 적용하면 시드 42에서 상위 3위에 든 인양 위험이 2→6건으로 늘었으나 추락은 32→26건으로 줄었다. 시드 137에서는 인양 5→5건, 추락 29→27건이었다. 두 시드 모두 최종 인양 경보의 적중은 0건이었다. 1회와 2회 사이의 순위·경보 변화는 학습한 파라미터가 늘어난 효과로 설명되지 않는다. 같은 연산량의 별도 블록도 비슷한 결과를 냈다.

24차원으로 압축하면서 잃은 정보와 반복 자체의 효과를 더 구분하기 위해 추가 실험의 비율을 한 번 고정했다. 768차원 선형 모델 확률 75%와 패치 모델 확률 25%를 더한다. 1회와 2회 조건에 같은 비율·임곗값을 적용한다. 이 비교는 위 표를 본 후 설계했다.

| 전체 사진 + 별도 블록 2회 | 126 / 129 | 0.2287 / 0.2287 | 20 / 19 | 7 / 7 | 4 / 4 |

전체 사진 단독 대비 공유 2회 결합의 순위 적중은 8건과 10건 늘었는데, 1회 결합만으로도 각각 7건과 9건 늘었다. 두 번째 공유 블록의 순위 순증은 각 시드에서 1건이었으며, 두 시드 모두 1회 결합보다 Macro F1이 낮았다. 2회 결합의 인양 위험 상위 3위 적중은 9건과 12건이었으나 최종 적중은 모두 4건이었다. 현재 제출 모델에는 이 형태의 반복을 채택할 근거가 부족하다. 근거 문장으로 유도한 후보 순위가 새 사건의 실제 경보까지 개선되는지가 남은 질문이다.

두 번째 전체 실행에서 시각 그리드의 SHA-256과 첫 비교의 두 시드 전체 지표가 그대로 재현됐다. 예열된 소형 분류기만의 CPU 중앙시간은 1회 약 0.030ms, 공유 2회 0.053~0.055ms였다. 이 숫자에는 시각 인코더와 한국어 생성기가 빠져 있다. [전체 코드별 적중·오경보와 시간](../results/loop_pilot.json)

## 독립 검증과 배포 선택

현재 적용 우선순위는 근거 지도 학습 실험 안에 포함하는 소형 판독기다. 한국어 근거·예방조치·출처 생성까지 담당하는 Qwen 시각층 개조는 이보다 뒤에 둔다.

후속 비교에서는 전체 사진 패치에 코드별 한국어 관측 근거를 감독 신호로 사용한다. `근거 사용 여부 × 공유 블록 1·2회`의 네 조건을 같은 사건 분할에서 비교한다. 같은 코드 내 근거 셔플은 문장에 담긴 사진 고유 정보의 대조다. 더 많은 파라미터와 더 많은 연산의 효과는 2개 독립 블록으로 확인한다. 최종 보류에서는 노출 제외 목록 182장과 확인된 동일 사건을 빼며, 실제 양성 사건이 부족한 위험의 재현율은 분모와 함께 보고한다.

Qwen 시각층 반복과 적응형 조기 종료는 제안된 별도 단계다. 고정 2회가 독립 사건에서 근거를 보인 뒤에만 검토한다. 조기 종료는 개발 사건에서 보정하며, 같은 평균 블록 호출 수의 무작위 추가 연산과 비교한다. 위험에 대한 잘못된 확신으로 일찍 끝나는 사례를 따로 센다. 제출 후보에는 기존의 Macro F1 +0.02 이상, 미관측 오경보 +3%p 이내, 중대한 위험 완전 미탐 비증가 기준을 적용한다. 최종 오프라인 Linux L4의 공식 200장·설치 포함 30분 조건에서 근거·조치 생성까지 측정한다.
