# 위험 근거와 예방조치의 눈가림 비교

같은 현장 사진과 같은 예측 코드에서 한국어 한 구절을 바꾸면 사진 근거 또는 조치의 적절성에 대한 사람의 판단이 달라지는지 조사한다. 평가 단위는 문구 한 쌍이다. 코드의 정답 여부는 주어지지 않는다. 참가자의 선호, 공식 LLM 점수, 분류 성능은 서로 다른 측정값이다.

## 표본과 통제

공개 사진의 기반 모델 원생성, 6장 프롬프트 비교, 18장 어댑터 배율 비교를 각각 집계한다. 6장·18장은 이미 개발 과정에 노출된 범위다. 어댑터는 대회 측이 학습했다. 같은 사진의 여러 생성 조건을 새로운 사진으로 세지 않는다. 프롬프트에서 사진을 교환한 조건은 실제로 입력된 사진에 연결한다.

프롬프트 요청에서 모델이 문구를 반환한 건만 원생성 수에 포함한다. 토큰 한도로 중단된 응답도 원생성 수에 포함하며, 문항 구성에는 정상 종료해 위험 목록이 파싱된 응답을 사용한다. 어댑터 배율 실험은 등록된 사진 순서에 따라 생성 직후의 개별 기록부터 반영한다. 완성된 18장 파일이 도착하면 앞선 개별 기록의 내용과 사진 식별자를 대조하고 같은 생성은 한 번만 센다.

한 코호트 안에서 사진당 근거 한 쌍과 예방조치 한 쌍까지 준비한다. 한쪽은 저장된 원생성의 해당 필드 전체다. 다른 쪽은 그 필드에서 실제로 한 번 나타나는 연속 구절 하나만 바꾼다. 준비자가 양쪽의 행동 지시를 먼저 검토한다. 준비자가 위험한 행동을 권한다고 판단한 문구는 평가자에게 제시하지 않는다. 양쪽을 고를 수 있다는 판단은 어느 한쪽에 투표한 결과가 아니다.

원생성 파일, 사진과 원필드 해시를 대조한다. 두 문구의 NFC 유니코드 글자 수, UTF-8 바이트 수, 공백 기준 어절 수와 공식 Qwen 토크나이저 토큰 수가 모두 같아야 한다. 토큰 수는 특수 토큰을 제외한다. 토큰 길이 통제가 문법, 친숙함, 문체의 영향을 완전히 제거하지는 않는다.

## 로컬 재현

프로젝트 루트에서 다음 명령을 실행한다. 저장된 결과만 사용하며 GPU 서버를 기동하지 않는다. 대회 원본을 갖춘 연구 PC의 승인된 문구 변형 목록이 필요하다.

```powershell
python -m kwater_lab.preference_pilot --inventory-only
python -m kwater_lab.preference_pilot
python -m kwater_lab.preference_pilot --score-only
```

원본 모델 응답과 사진을 확인한 준비자는 `data/preference-pilot/recipes.json`에 생성 식별자, 코드, 필드, 바꿀 두 구절, 준비자 안전 확인, 원필드·사진·생성 파일의 SHA-256을 기록한다. 새 쌍을 추가할 때 기존 항목의 순서를 유지한다. 새 문항끼리만 순서를 섞어 기존 평가지 끝에 붙인다. 원문을 포함하는 이 목록, 눈가림 키, 사진, 양식 및 개별 응답은 모두 로컬에 둔다.

평가자에게는 같은 디렉터리의 `blind/review.html`과 `blind/blank.csv`만 안내한다. HTML은 로컬 사진을 표시한다. 실제 평가자는 CSV 사본을 `ratings`에 평가자별 한 파일로 저장한다. 각 행에서 A, B, 동률, 양쪽 부적절, 판단할 정보 부족 중 하나를 선택할 수 있고 빈 선택은 미평가로 유지한다. 평가 자료에는 원문 여부, 사전 정답, 생성 조건, 다른 평가자의 답이 표시되지 않는다. 원문의 A/B 위치는 코호트와 필드 안에서 균형이 맞도록 배치하고 문항 순서를 별도로 섞는다.

`--score-only`는 사진·후보 문구·코드·키를 다시 대조하고 실제 응답을 집계한다. 형식 외 선택, 같은 평가자 파일 내 문항 중복, 알 수 없는 문항은 오류로 처리한다. 원문 선호 비율은 원문과 변형 중 하나를 고른 투표에서만 계산한다. 해당 투표가 없으면 값은 비워 둔다.

[집계 결과](../results/preference_pilot.json)에는 코호트별 목표 사진 수, 관측된 생성 횟수, 위험 목록이 읽힌 횟수, 실제 사진 수, 쌍에 사용된 생성 횟수, 근거·조치 쌍 수 및 사람 평가 수가 담긴다. 준비하지 않은 쌍과 평가자가 남긴 판단은 구별한다.

6장 프롬프트 실험의 30회 응답 중 28회에서 위험 목록을 읽었고 2회는 토큰 한도에 도달했다. 근거 문항은 사진 6장 모두에서, 예방조치 문항은 3장에서 만들었다. 나머지 세 사진은 원문이 추가 조치를 제시하지 않았거나 노출된 전기설비나 붕괴 구조물 주변의 직접 작업을 언급해 양쪽 문구를 평가 대상으로 채택하기 어려웠다. 선정 과정은 사람이 남긴 선호 투표 수에 포함하지 않는다.

18장 어댑터 실험은 같은 사진을 배율 1.0과 0.75로 한 번씩 처리해 총 36회 생성했다. 두 배율이 모두 빈 위험 목록을 반환한 5장에서는 비교할 근거나 조치가 없었다. 나머지 13장에는 사진마다 근거와 조치 문항을 각각 하나씩 준비했다. 먼저 도착한 배율 1.0의 응답에서 24쌍, 0.75에서 2쌍을 구성했다. 이 양식에서 평가자가 고르는 두 후보는 한 응답에서 한 구절을 달리한 문구다. 배율별 우열을 평가하려면 두 배율에서 얻은 원문을 직접 비교하는 별도의 설계가 필요하다.
