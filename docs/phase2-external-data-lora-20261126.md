# 외부 안전 데이터로 Qwen LoRA를 개선할 수 있는가

2026년 11월 26일 · K-water 현장 안전 AI · 실험 항목 #38

**첫 외부 학습은 AI-Hub 71407의 추락 방호 상태 비교쌍으로 한정한다.** 기존 탐색에서 이 자료의 실제 라벨이 추락 정답을 2장 더 찾았고 무작위 라벨보다 오탐이 적었다. 전체 위험 F1과 무위험 오경보에서는 채택 근거가 부족하다. 외부 학습의 가치는 동일한 Qwen을 대회 자료만으로 훈련한 경우와 새로 비교한다.

## 확보량과 근거

11월 26일 15:05 KST에 원본 패키지 ZIP의 실제 바이트 수, SHA-256 형식이 유효한 기존 무결성 기록 및 ZIP 내부 CRC 검사 건수 양수를 대조했다. 등록된 484개 중 71407은 448/452, 507은 16/27, 71793은 4/5로 총 468개가 일치했다. 이번 집계는 해시 재계산이나 장면·주석 적격 판정과 별개다. 원본과 라벨 ZIP이 모두 있고 영상·프레임·시나리오가 대응하는 단위만 학습 후보로 센다.

동일한 대회 탐색 사진 170장, 위험 사진 104장, 무위험 66장에 대한 기존 분류기 원자료를 다시 비교했다. 이 사진은 개발에 이미 노출되었고 접두사 여섯 개가 실제 독립 사건이라는 보장은 없다.

## 첫 LoRA 비교

1. **분할과 학습 목표를 고정한다.** 대회 데이터는 기존 개발 분할을 재사용한다. 외부 자료는 같은 현장·원본 영상·근접 프레임을 한 그룹에 묶고, 대회 자료와의 중복은 개발용 식별 정보로 검사한다. 동일 외부 그룹의 정상·비정상 쌍은 같은 분할에 둔다. Qwen에는 사진 한 장과 한 가지 상태 질문을 주고 보이는 방호 증거만 답하게 한다. 출처·폴더명·시나리오 표기는 모델 입력에서 뺀다. 주석이 없는 다른 10종은 미관측으로 유지한다.
2. **대회 자료만으로 학습한 Qwen LoRA를 기준으로 삼는다.** 같은 초기 가중치·학습 분할·시드·어댑터·업데이트 수·시각 및 답변 토큰 예산·대회 데이터 마무리 학습을 고정한다. 보조 배치에 (A) 대회 자료 재표집, (B) 71407 실제 상태쌍, (C) 같은 외부 사진에서 상태 응답을 순열한 대조를 넣는다. B와 C의 이미지·질문·정상/비정상 빈도를 맞춘다. 순열은 상태가 실제로 바뀐 비율을 기록한다. 주 실험에서는 세 조건의 외부 또는 대체 배치 비율을 훈련 예산의 10%로 시작한다. 작은 표본 때문에 같은 영상의 프레임이 반복되면 현장별 상한을 걸고 독립 영상 수를 보고한다. 탐색 범위 확대 전에 기준 모델 한 종에서 먼저 비교한다.
3. **외부 학습이 무엇을 바꾸는지 측정한다.** 동일 대회 사진의 공식 방식 Macro F1·11종 고정 F1, 추락 정답 회복과 새 오탐, 무위험 사진 오경보, 중대성 4 완전 미탐을 함께 기록한다. 짝별로 맞힌 쪽이 바뀐 사진 수와 사건 그룹별 변화도 보고한다. 양성 사건이 한 그룹뿐인 코드는 별도 표시한다. 설명은 같은 위험 코드에서도 사진에 보이는 단서를 제시하는지, 없는 보호구·난간·법령을 지어내는지, 조치가 그 위험에 맞는지 모델명을 가리고 비교한다. 평가용 법령·출력 조립·재판독 조건은 고정한다.
4. **승격은 공식 개발 자료에서 정한다.** 작은 패널은 로더·학습·응답 검증과 방향 탐색에 쓴다. 실제 라벨 모델이 대회 재표집과 순열 모두를 넘고, 그룹별로 결과가 한 현장에 쏠리지 않으며, 무위험 오경보·중대 위험 완전 미탐·근거 품질의 기존 승격 기준을 지키는지 개발 920장 그룹 검증에서 확인한다. 결과가 불확실하면 공식 데이터 모델을 유지한다. 유망할 때만 507을 독립 비교한 다음 조합과 다른 Qwen 세대로 확장한다. 125장 봉인본은 기존 Phase 3의 단일 고정 후보 검증에만 사용한다.
