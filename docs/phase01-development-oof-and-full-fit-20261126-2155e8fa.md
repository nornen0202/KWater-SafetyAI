## 모델과 정보 경계

각 외부 fold의 표준화 평균·분산, 클래스 사전확률, 분류기 가중치와 근거 대상은 외부 학습 사진에서만 추정했다. 바깥 검증 라벨은 학습·보정에 쓰이지 않는다. 바깥 학습 그룹을 다시 3-fold로 갈라 얻은 내부 OOF에서 온도, 공통·클래스별 임계값, F1/2 순위 오프셋과 장면 게이트를 고른다. 양성 그룹 2개 미만이면 온도 1과 공통 임계값을 적용하며, 헤드 학습에 양성 0개면 해당 점수를 억제한다. 양성 n개 클래스 임계값의 공통값 가중치는 20/(n+20)이다. Gate·임계값 통과 코드 중 최대 3개만 출력하며 0개면 무위험이다. 단일 고정 대조는 보정 없는 0.20이다. 근거 텍스트는 학습·성능 비교를 위한 입력과 분리해 추론 때 기존 코드별 문구를 쓴다.

개발 OOF에서 ΔF1 ≥0.02이고 무위험 오경보율이 기준 이하 또는 20% 이하이며 중대성 4 완전 미탐이 감소하고 쌍체 그룹 부트스트랩 95% 구간 하한이 0을 넘을 때만 승격한다. 판정 정책을 고정하고 개발 전용 모델을 저장한 후에만 최종 1,045장 가중치를 학습했다. 부트스트랩은 같은 그룹 단위로 2,000회 복원 추출(seed 42)했다. 10개 정책 중 선택에도 같은 개발 OOF를 사용했으므로 선정 모델 점수에는 선택 편향이 남는다. 표의 신뢰구간은 각 정책의 고정 예측을 짝지어 얻었으며 정책 간 다중 비교나 재학습 변동까지 보정하지 않는다. 공식 학습에 사진 1장뿐인 3종은 한 그룹을 제외하거나 다시 뽑을 때 클래스별 결과가 크게 달라질 수 있다. 재표집에 그 클래스의 정답·예측이 모두 빠지면 해당 표본의 평균 분모에서도 빠진다.
