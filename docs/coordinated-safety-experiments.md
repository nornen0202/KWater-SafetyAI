# 관측 근거, 희귀 위험, 상대 깊이, 예방조치의 공동 실험

2026년 11월 25일. 대회 자동평가 100점 중 위험 유형별 F1은 70점, 한국어 판단 근거는 12점, 예방수칙은 12점, 출처는 6점이다. 메인 세션은 한국어 생성·눈가림 검토와 현장 상태 쌍, 외부자료 사이드는 상대 깊이와 원본 영상 추적, 실험 분석 사이드는 한국어 근거·경보 선택·희귀 위험·RGB 전용 증류·생성문 법령 평가를 맡았다. [대회 평가 기준](https://hackathon.imaginationgroup.co.kr/kwater/#evaluation)

## 실행 순서

1. 기존에 노출된 170장에서 사진별 관측 근거 사용 여부와 출력 규칙을 교차 비교한다. 같은 분할에서 추락·걸림·인양물의 모의 희귀 비교를 수행한다. 가능한 경우 각각의 추론 입력은 사진 하나로 고정한다.
2. 추락과 인양부터 실제 위험·방호 상태가 달라지는 대응쌍을 확인한다. 외부 정상·비정상 시나리오의 영상·현장 중복을 대조하고, 동일 상태 변화로 볼 수 있는지 사진을 검토한다. 내·외부의 실제 관측 사례를 유지한 채 깊이 모델의 순증을 구한다. [상대 깊이 비교 설계](depth-pilot-protocol.md)
3. 완성된 생성물부터 같은 사진·코드에서 한 구절만 다른 근거·예방조치를 비교한다. 공개 예시, 6장 판독, 18장 어댑터 배율은 서로 다른 코호트다. 생성·쌍 제작·사람 투표의 수를 각각 추적한다. [눈가림 평가 설계](preference-pilot.md)
4. 독립 사건과 표본을 확정한 뒤 개발·보류를 분리한다. 182장과 확인된 동일 사건을 최종 보류에서 제외하고, 배포 어댑터의 훈련 내 진단은 독립 효과에서 분리한다. 분류 후보는 Macro F1 +0.02 이상, 미관측 오경보율 증가 3%p 이내, 중대한 위험 완전 미탐 비증가를 확인한다. 선호 학습 후보는 새 사건의 눈가림 판정에서 사진 밖 단정과 부적절한 조치가 줄어드는지 측정한다. 제출 전 오프라인 L4에서 설치·기동·생성을 모두 측정한다. [기존 승격 기준](improvement-experiments.md)

## 사진별 관측 근거와 경보 선택

SigLIP 2 384 선형 분류기와 영상 이웃을 반씩 섞은 기준선을 재현했다. 학습 사진의 `evidence`와 미관측 사진의 `scene_evidence`에서 명시적인 사고명·조문 표현을 제거하고 한글을 포함한 문자 2·3그램으로 표현했다. 사진 특징에서 근거 벡터를 예측하도록 릿지 회귀를 학습했다. 추론 사진에는 정답 문장을 제공하지 않는다. 예측한 근거로 조회한 학습 이웃의 점수는 25%만 사용했다. 같은 코드 내에서 근거 문장을 다른 학습 사진으로 순환 교환한 조건이 대조다. 사진 전체의 간단한 문자 기반 실험으로, 패치별 한국어 의미 정렬은 추가 검증 대상이다. [학습 시 추가 정보를 사용하는 증류](https://arxiv.org/abs/1511.03643)

6개 접두사 중 하나를 검증에 두고 나머지에서 다시 내부 교차검증했다. 공통 임곗값과 0~3개 경보의 예상 Macro F1 기여도는 각 내부 예측으로 보정했다. 기여도는 내부 분할의 활성 코드에서 점수 구간별 적중 비율을 보정하고, 현재 F1과 양성·예측 건수를 이용해 경보 한 개를 추가할 효과를 근사한다. 같은 사진별 경보 개수를 고정한 대조도 별도로 계산했다. [Macro-at-k 원 연구](https://arxiv.org/abs/2401.16594) · [코드별 수치와 보정 조건](../results/evidence_factorial.json)

| 사진 모델과 출력 규칙 | Macro F1 | 미관측 오경보 / 66 | 추락 적중 / 34 | 인양·낙하물 적중 / 19 |
|---|---:|---:|---:|---:|
| 사진 기준선 · 공통 임곗값 | 0.2438 | 29 | 9 | 5 |
| 한국어 근거 지도 · 공통 임곗값 | 0.2442 | 34 | 12 | 5 |
| 사진 기준선 · 예상 기여도 | 0.2325 | 60 | 24 | 6 |
| 한국어 근거 지도 · 예상 기여도 | 0.2338 | 60 | 24 | 4 |
| 같은 코드 내 근거 교환 · 공통 임곗값 | 0.2361 | 39 | 11 | 6 |

임곗값 적용 전 상위 3위에 포함된 정답은 149건 중 사진만 116건, 정합 근거 121건, 교환 근거 117건이었다. 정합 근거의 F1 증가는 0.00044, 미관측 오경보 증가는 7.58%p였다. 미확정 접두사 6개를 쌍으로 재표집한 F1 차이의 95% 참고 구간은 −0.0170~+0.0153이다. 사건 독립성을 검증한 구간으로 해석하기 어렵다. 경보 개수를 사진마다 기존과 동일하게 고정해도 기여도 방식의 사진 단독 F1은 0.2381이었다. 현 단계에서는 근거를 이용한 후보 순위를 후속 검증에 남기고, 기여도 방식의 자유 경보 출력은 승격을 보류한다.

## 모의 희귀 위험과 실제 희귀 위험

추락·걸림·인양물은 여섯 접두사 모두에 양성이 있었다. 한 코드를 감춘 각 실험에서 해당 양성 사진과 그 사진의 모든 문장을 단서 전이 학습에서 제외했다. 해당 코드를 갖지 않는 학습 사진의 한국어 근거로 통로·단차·방호·인양물 등 11개 관측 단서의 언급 여부를 학습했다. 언급되지 않은 단서를 현장에 없다고 판정한 사람 라벨은 없다. 공개 CLIP의 위험·방호 대비 문장에 언급 예측을 결합하고, 동시에 필요한 단서는 최솟값, 여러 대안은 최댓값으로 결합했다. [조합형 인식 연구](https://arxiv.org/abs/2101.12609) · [다중라벨 소수 사례 학습](https://arxiv.org/abs/2110.13494)

0장에서는 텍스트만 사용한다. 1장·5장에서는 다른 학습 접두사당 양성 사진을 한 장씩 뽑아 다섯 번 반복했다. 각 반복에서 1장은 5장에 포함된다. 각 평가 사진의 점수·경보 임곗값 정규화에는 해당 검증 접두사를 사용하지 않았다. 평균 AP는 세 코드 각각의 정밀도-재현율 순위 점수(AP)를 평균한 값이다. 1·5장은 다섯 지원 표본 선택에 대해서도 평균했다. [코드·시드별 AP와 TP·FP](../results/compositional_pilot.json)

| 보여준 양성 사진 | 단순 대조 평균 AP | 단서 조합만 사용한 평균 AP | 다른 코드 기록에서 단서를 학습한 조합 평균 AP |
|---|---:|---:|---:|
| 0장 | 코드명 문장 0.2587 | 0.2256 | 0.2363 |
| 1장 | 사진 최근접 0.3165 | 0.2804 | 0.2832 |
| 5장 | 사진 최근접 0.2906 | 0.2769 | 0.2842 |

1·5장 행에서 두 단서 모델은 동일 지원 사진 점수를 각각 절반씩 사용했다. 최근접 1장의 반복별 세 코드 평균 AP는 0.282~0.368이었다. 소수 사진 선정의 영향이 크므로 이 결과로 최적 장수를 결정하지 않는다. 실제 희귀 3종은 전체 학습셋에서 각 1장, 이 탐색셋에서는 각 0장이다. 학습 음성의 상위 10%를 기준으로 고정한 이진 선별에서 전이 모델이 170장에 낸 오경보는 밀폐공간 21건, 익수·침수 19건, 온도·기상 14건이었다. 각각 미관측 66장만 보면 7·4·1건이다. 이 값은 실제 희귀 코드를 모두 함께 제출한 공식 점수와 분모가 다르다. 다음 판단에는 코드에 맞는 독립 양성 사건과 실제 방호된 유사 장면이 필요하다.

## 상대 깊이의 직접 입력과 RGB 전용 증류

외부자료 사이드에서 Depth Anything V2 Small을 로컬 CPU로 실행했다. 전체 사진에서 얻은 상대 깊이를 4×4 격자의 값·기울기 32차원으로 요약하고, 같은 차원의 명도·경계·다른 사진 깊이와 비교했다. 다음 비교에서는 이 단서를 학습 중에만 쓴다. 학생은 RGB 특징에서 32차원을 예측하며 학습 사진에 붙일 단서도 해당 접두사를 제외하고 추정했다. 검증 사진의 깊이를 제공하지 않고도 추론되는지 단위 테스트했다. 두 단계 모두 CLIP 선형 분류기, 임곗값 0.5, 사진당 최대 세 코드를 사용했다. 앞의 SigLIP 실험과는 기준선이 다르다. [모델 원 제공처](https://github.com/DepthAnything/Depth-Anything-V2) · [직접 입력 실측](../results/depth_pilot.json) · [RGB 전용 증류 실측](../results/depth_distillation.json)

| 조건 | Macro F1 | 미관측 오경보 / 66 | 추락 적중 / 34 | 인양·낙하물 적중 / 19 |
|---|---:|---:|---:|---:|
| RGB 기준 | 0.1950 | 13 | 7 | 0 |
| RGB + 2D 경계 | 0.1986 | 13 | 8 | 0 |
| RGB + 같은 사진의 추정 깊이 | 0.2212 | 14 | 7 | 2 |
| RGB + 다른 사진의 깊이 | 0.2152 | 11 | 9 | 1 |
| RGB 전용 · 같은 사진 깊이로 보조학습 | 0.1919 | 15 | 6 | 0 |
| RGB 전용 · 다른 사진 깊이로 보조학습 | 0.2017 | 11 | 7 | 0 |

직접 입력한 깊이의 F1 순증은 RGB보다 0.0262, 다른 사진의 깊이보다 0.0061이었다. 인양물의 실제 양성 두 건을 추가로 맞혔으며 전체 음성 151장에서 이 코드의 오탐은 13→6건이었다. 추락은 1건을 새로 맞히고 1건을 놓쳤다. RGB 전용 학생의 깊이 예측은 학습 분할 평균 예측 대비 R² 0.1245였으나, 위험 분류의 F1과 인양 적중은 개선되지 않았다. 170장 전역 특징에 붙인 선형 증류는 제출 승격을 보류한다. 다음 개발 우선순위는 인양물과 사람의 관계가 보이는 별도 사건에서 같은 사진 깊이와 대조 깊이의 차이가 반복되는지 확인하는 것이다.

공식 탐색 자료에서 전체 화면 50장·후보 26쌍을 모델이 검토해 상태 대비를 읽을 수 있었던 것은 추락 1쌍, 인양 2쌍이었다. 사람 확인이나 동일 사건 판정은 0건이다. AI-Hub에서는 제공자 정상·비정상 라벨이 있는 8쌍(서로 다른 영상 16개, 현장 5곳)을 확보했다. 깊이를 직접 쓴 분류기가 비정상 사진에 더 높은 점수를 준 것은 추락 2/7쌍, 크레인 0/1쌍이었다. 현장·설비 등도 함께 달라질 수 있어 위험 상태 하나의 인과 효과는 이 비교로 분리하기 어렵다. ## 근거·예방조치의 사람 선호

공개 사진 1장의 실제 생성문에서 근거 1쌍과 예방조치 1쌍을 만들었다. 같은 사진·같은 코드에서 한 구절만 바꾸었으며 공백 기준 어절 수, 문자·바이트·Qwen 토큰 길이를 맞췄다. 집계 시점의 사람 평가는 0/2쌍이다. 6장·18장 생성 자료가 도착하면 각 표본의 문항 수와 투표 수를 별도로 기록한다. 24점 항목의 개선 폭은 미측정이다. 실제 독립 선호가 쌓이면 같은 사진·동일 예산에서 선호 학습과 채택 문장만 지도학습한 조건을 비교한다. 목적 지표는 사진 밖 단정, 관측과 조치의 연결, 블라인드 선호 승률이다. [문항 생성과 투표 집계](../results/preference_pilot.json) · [문구 단위 선호 학습 연구](https://arxiv.org/abs/2312.00849)

## 실제 생성문의 인용 검색

생성된 코드와 문구에 학습 분할 코드별 최빈 조문, 본문 2그램 BM25, 학습 사례 검색, 사례·예방조치 순위 재정렬을 적용했다. 공개 사진 한 장의 구조화 응답에는 위험 두 개가 있었고, 두 실제 정답 중 코드와 첫 조문을 함께 맞힌 수는 네 방법 순서대로 1·0·1·1건이었다. 네 방법 모두 잘못 판독한 위험에도 실제 조문을 하나 붙였다. 기본 Qwen과 Qwen3.5의 다른 질문 조건도 같은 공개 사진을 사용했다. 18장 배율 하나의 생성이 끝나면 같은 명령이 사진 순서·배포본 해시·생성 스키마를 확인해 집계한다. 키트 검사가 끝나면 코드와 실제 근거·조치 문구까지 원문과 대조한다. 같은 접두사와 동일·근접 사진을 사례집에서 제외하고, 검토된 사건 원장이 생기면 같은 사건도 제외한다. 조문 ID 적중을 집계했으며, 조문이 실제 조치를 뒷받침하는지는 별도 평가가 필요하다.
